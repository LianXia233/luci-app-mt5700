第 1 步：SSH 登录确认系统架构与包管理器 
grep OPENWRT_ARCH /etc/openwrt_release
第 2 步：校验 SHA256 并覆盖安装（含简体中文语言包） 
# 校验下载完整性
grep -E 'luci-app-mt5700|luci-i18n' SHA256SUMS | sha256sum -c -

# OpenWrt 25.x / ImmortalWrt SNAPSHOT (apk)
apk add --allow-untrusted ./*luci-app-mt5700-*.apk ./*luci-i18n-mt5700-zh-cn-*.apk

# OpenWrt 24.10 (opkg)
opkg install ./*luci-app-mt5700_*.ipk ./*luci-i18n-mt5700-zh-cn_*.ipk
Debian / Ubuntu 独立宿主机部署（带 systemd 与 9000 端口 WebUI） 
sudo apt install ./at-webserver_1.32.13-1_amd64.deb
# 安装完成后访问 http://<设备IP>:9000
加入 OpenWrt / ImmortalWrt SDK Feeds 源码编译 
# 在 feeds.conf.default 末尾追加
src-git mt5700 https://github.com/LianXia233/luci-app-mt5700.git

# 更新并安装到编译树
./scripts/feeds update mt5700 && ./scripts/feeds install -a -p mt5700

常见问题与升级说明

汇总安装门槛、驱动依赖、缓存刷新与夜间模式排查要点

Q1: 为什么不能与 QModem 同时运行？

MT5700M 模组通常仅提供单个 AT 主串口（如 /dev/ttyUSB2）。本插件通过串口互斥锁保障拨号、轮询、测温与短信事务串行稳定，若同时运行 QModem 会造成串口争抢与报文错乱。

Q2: 为什么需要 OpenWrt 23.05 及以上版本？

RPC 桥接依赖 rpcd-mod-ucode 加载 /usr/share/rpcd/ucode/mt5700.uc，该组件从 OpenWrt 23.05 起随 luci-base 引入；22.03 及更早固件缺少默认支持，推荐使用 OpenWrt 24.10 或 25.x。

Q3: 串口列表找不到 ttyUSB2 怎么办？

请确认固件已包含 USB 串口驱动 kmod-usb-serial-option 与网卡驱动 kmod-usb-net-cdc-ncm，并检查模组供电及 M.2 / USB 物理连接。

Q4: 覆盖升级后页面样式/功能没有变化？

OpenWrt 的 uhttpd 对静态资源返回 Last-Modified: 1970，浏览器可能命中旧缓存。升级后请按 Ctrl + F5 强制刷新，或重新登录 LuCI 触发 MT5700_UI_VERSION 缓存失效。
