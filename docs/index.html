📦 快速部署

安装与快速上手指南

⚠️
独占模组串口说明（与 QModem 互斥）

本插件为 MT5700M 专用拨号套件，直接接管并独占模组串口。使用本插件即可全自动完成拨号，无需安装或运行 QModem。请在安装前卸载或停用其他会占用同一串口的插件。

支持 OpenWrt 24.10 及更早版本（使用 opkg 安装 .ipk），以及 OpenWrt 25.x / ImmortalWrt SNAPSHOT（使用 apk 安装 .apk）。

第 1 步：SSH 登录路由器，确认 CPU 架构
grep OPENWRT_ARCH /etc/openwrt_release # 如 aarch64_cortex-a53 或 x86_64
第 2 步：下载对应架构包并安装 (以 OpenWrt 24.10 opkg 为例)
# OpenWrt 24.10 / ImmortalWrt (opkg)
opkg install ./<ARCH>-luci-app-mt5700_*.ipk ./<ARCH>-luci-i18n-mt5700-zh-cn_*.ipk

# OpenWrt 25.x (apk)
apk add --allow-untrusted ./<ARCH>-luci-app-mt5700-*.apk ./<ARCH>-luci-i18n-mt5700-zh-cn-*.apk

支持作为独立服务部署在 Debian 11/12、Ubuntu 22.04/24.04、Armbian 等 Linux 主机或工控机，提供 systemd 守护进程与独立 WebUI。

Debian / Ubuntu 安装命令
# 64 位 x86_64 设备
sudo apt install ./at-webserver_*_amd64.deb

# 树莓派 / ARM64 设备
sudo apt install ./at-webserver_*_arm64.deb

安装完成后由 systemd 自动开机自启，浏览器直接访问 http://<设备IP>:9000。

将插件直接集成进 OpenWrt / ImmortalWrt 固件源码编译：

# 1. 在 feeds.conf.default 末尾追加
src-git mt5700 https://github.com/LianXia233/luci-app-mt5700.git

# 2. 更新与安装 feeds
./scripts/feeds update mt5700 && ./scripts/feeds install -a -p mt5700

# 3. 在 make menuconfig 中勾选
LuCI > 3. Applications > [*] luci-app-mt5700

💡 解惑答疑

常见问题与排坑速查

汇总用户常见使用疑问、驱动配置与版本门槛说明

Q1: 为什么不能与 QModem 共存？

答：MT5700M 模组在固件中通常仅提供一个 AT 指令主串口（如 /dev/ttyUSB2）。本插件为了确保信号轮询、温度采集与短信编解码的绝对稳定，会对串口实施严格的独占互斥调度锁。若同时运行 QModem 会引起串口争抢与报文错乱。本插件内置完备的自动拨号机制，无需再安装 QModem。

Q2: 为什么 OpenWrt 21.02 及更早版本无法运行？

答：插件的前端 RPC 桥接基于 rpcd-mod-ucode，该组件自 OpenWrt 22.03 起随系统正式预装。老版本系统缺失 ucode 解释器，装上后会出现“能开页面但所有操作均报 Method not found”。请升级至 OpenWrt 24.10 或 25.x。

Q3: 安装后在串口列表找不到 ttyUSB2？

答：本插件为管理服务，不含底层 Linux 内核驱动。您的路由器固件需要包含 USB 串口驱动（kmod-usb-serial-option）以及网卡驱动（kmod-usb-net-cdc-ncm）。若设备树未识别，模组硬件可能未正常通电。

Q4: 短信发送失败，提示时延超预算？

答：请先检查 SIM 卡是否支持短信收发功能（部分纯物联网流量卡默认被运营商关闭短信功能）。其次检查是否已在“短信设置”中正确配置该 SIM 卡归属运营商的短信中心号码（SMSC），格式需为国际格式（如 +8613800...）。
