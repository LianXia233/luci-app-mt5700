# v1.25.1

**主题**：状态页三张卡片（信号强度 / 网络状态 / 流量统计）的内容底边齐平。纯样式修正，前端一个 CSS 块，无接口、无后端、无逻辑改动。

---

## 1. 现象

v1.25.0 把网络状态卡片重做成「链路拓扑 + 2×3 信息格」后，在宽度足够排成三列时，网络状态卡片的下方明显空出一块，三张卡看起来没有对齐。

## 2. 根因

三张卡在同一个 CSS Grid 行里，网格会按「该行最高的那张」把它们**拉成等高** —— 实际三张都是 422px，外框底边本来就是齐的。问题不在外框，在**内容没铺满**：

| 卡片 | 内容实际占高 | 与卡片底边的间隙 |
| --- | --- | --- |
| 信号强度 | 铺满（SSB 矩阵两行） | 1px |
| 网络状态 | 信息格盒子 222px，内容仅 147px | **75px** |
| 流量统计 | 铺满 | 1px |

信息格 `.mt-net-info-grid` 是 `flex: 1`，会被拉满剩余高度；但它是 CSS Grid 且原本写着 `align-content: start` —— 三行各自按内容高度排在顶部，被拉出来的 75px 全部堆在最后一行下面。从外面看就是「卡片下面空了一块」。

## 3. 修法

```css
.mt-net-info-grid {
  grid-auto-rows: 1fr;      /* 三行等分可用高度 */
  align-content: stretch;
  align-items: center;      /* 单元格在各自行内垂直居中 */
}
```

六格均分剩余高度，最后一行正好压在卡片底部内边距上；相邻两卡的内容底边因此齐平。

没有改成「把空白对半分给拓扑区」：那会让标题与拓扑之间出现一段无来由的大空档。分给信息表更自然 —— 它本来就是个表格，行距均匀比挤成一堆更好读。

**单列布局（≤1024px）不受影响**：那时卡片高度由内容决定，`flex: 1` 分不到额外空间，行高回落到内容高度。

## 4. 验证

实机（内网测试机，ImmortalWrt SNAPSHOT / aarch64_cortex-a53）逐宽度测量三卡的卡片高度与「卡片底边 − 内容底边」间隙：

| 视口宽度 | 三卡高度 | 内容间隙 |
| --- | --- | --- |
| 1400px | 422 / 422 / 422 | 1 / 1 / 1 px |
| 1200px | 422 / 422 / 422 | 1 / 1 / 1 px |
| 1100px | 422 / 422 / 422 | 1 / 1 / 1 px |

修复前 1400px 下网络状态卡的内容间隙为 75px（信息格内容 147px / 盒子 222px），修复后为 1px；另外两张卡不受影响。

`MT5700_CSS_VERSION` 2.28.0 → 2.29.0，避免浏览器继续用缓存里的旧样式。

## 5. 升级注意

只改一个 CSS 块，升级后若页面样式没变，硬刷新一次即可。
