**日志页重构版** —— 把排障最需要、此前却看不到的过程日志补上。

### 新增

- **模组拨号视图**：后端内存日志。含自动拨号对齐、数据承载与 USB 网卡状态、串口探测与选口过程、主动上报分发。稳态下后端日志级别是 Warn，这些 info 级日志不会写进 syslog —— 现在通过内存缓冲直接给页面用。
- **接口与网络视图**：init.d 的输出（接口拉起与重试、热插拔、动态地址与 IPv6 取址结果）与后端接口相关日志合并展示。
- **通知记录视图**：保持原有短信 / 来电 / 信号 / 存储告警记录。

### 界面

- 级别中文化：调试 / 信息 / 警告 / 错误，各配一色（左色条 + 徽章），亮暗主题都成立
- 术语中文映射：`SETAUTODIAL`→自动拨号、`PDP`→数据承载、`DHCP`→动态地址分配…（AT 命令名保持原文；搜索仍按原文匹配）
- 毫秒级时间列、关键词高亮、级别 + 关键词双过滤、自动刷新（页面不可见时暂停）、一键导出、条数统计
