# v1.21.0

**主题**：SIM 卡信息新增「签约速率」显示。

## 数据来源

`AT+C5GQOSRDP=1`（3GPP TS 27.007，5GS QoS 动态参数）。响应形如：

```
AT+C5GQOSRDP=1
+C5GQOSRDP: <cid>,<5QI>,<GFBR上行>,<GFBR下行>,<MFBR上行>,<MFBR下行>,<Session-AMBR上行>,<Session-AMBR下行>
```

字段单位均为 **kbps**。

- 非 GBR 类 5QI 下，GFBR/MFBR 四个字段按规范留空；
- 末尾两个非空值即核心网下发的 **Session-AMBR**，也就是这张卡的签约上下行上限。

界面显示为 `↑ <上行> / ↓ <下行>`，按十进制换算、不凑整。

## 关于 4G

这条命令在 4G / 5G 下**都不会报错**，但 4G 下本固件只回：

```
+C5GQOSRDP: 1,0,,,,,,
```

即 `5QI=0`、速率字段全空。为此在 4G 下额外排查过以下命令，**全部返回 ERROR**：

| 命令 | 4G 实机结果 |
|:--|:--|
| `AT+CGCONTRDP` / `=1` / `?` | ERROR |
| `AT+CGEQNEG` / `=1` | ERROR |
| `AT+CGEQREQ?` / `AT+CGEQMIN?` | ERROR |
| `AT+CGQREQ?` / `AT+CGQMIN?` | ERROR |
| `AT+C5GQOSRDP=2/3/5/6/8/11`（其它 cid） | ERROR（模组仅支持 cid=1） |
| `AT^AMBR?` / `AT^UEAMBR?` / `AT^EPSAMBR?` / `AT^LTEAMBR?` / `AT^SESSIONAMBR?` 等 20 余个私有命令 | ERROR |

排查方式：`AT^SYSCFGEX="03",...` 临时切到仅 4G，等 35s 注册到 LTE（`+CEREG: 2,1`）后逐条探测，结束后已切回 `"080302"`（5G 优先）并确认 `+C5GREG: 2,1`。

**结论：本固件在 4G 下不上报签约速率。** 因此 4G 时该行显示「模组未上报」，而不是用别的参数凑一个假数值——这符合本项目"绝不伪造数据"的一贯原则。

## 界面

「SIM 卡信息」页（中部 Tab 卡片的第 3 个 Tab）新增一行，鼠标悬停可看到取值来源说明：

| 字段 | 5G (SA) | 4G (LTE) |
|:--|:--|:--|
| 签约速率 (Session-AMBR) | `↑ <上行> / ↓ <下行>` | `模组未上报` |

> 后续 v1.21.2 起改用厂商命令 `AT^DSAMBR`，4G 也能取到真实签约速率。
