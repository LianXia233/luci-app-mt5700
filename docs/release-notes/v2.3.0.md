# v2.3.0 — 同步 main v1.24.3 → v1.32.5（后端 + 前端）

**v2.3.0 把 `main` 分支 v1.24.3 之后到 v1.32.5 的全部业务能力搬回 `Debian` 分支**，
分两批执行：批次一搬 Rust 后端（提交 `6696299`，31 文件），批次二搬 WebUI
（提交 `0091170`，178 文件）。仍沿用 v2.2.0 的「纯内容搬运」口径 ——
不产生与 `main` 的 merge 血缘提交，同步点只记录在本分支 `CHANGELOG.md`。

> 版本口径：本分支版本号与 `main` 完全独立。本次只在 `src/rust/Cargo.toml` 把 deb 包版本
> 提至 `2.3.0`（`debian/build-deb.sh` 单点 `sed` 读取，无第二处），
> **不引入 `main` 的 `1.32.5` 编号，也不引入 `MT5700_UI_VERSION` 常量**。

### 背景

- **后端落后两个世代**：本分支停留在 v1.24.3 快照，`main` v1.32.5 的 `src/rust`
  规模约为其 3 倍，新增短信业务、本地归档、QQ 推送/扫码绑定、信号等级与定时巡检、
  定时实际情况推送等模块。
- **前端整整落后 8 个版本**：v1.25~v1.32 带来明暗主题体系（`theme.js`）、极简 MD3
  模式（`uimode.js` / `md3.css`）、图标体系（`icons.js` + 200 余个资源文件）、
  窄屏 Tab 悬浮菜单（`tabmenu.js`）、短信页夜间模式、QCI/5QI 展示等。
- **不能整分支合并**：本分支自 `76d1f82` 起把 `htdocs/` 搬到 `webui/`、删除
  `Makefile` / `root/` / `po/` / `scripts/`、新增 `debian/` 与自制加载器
  （`webui/luci.js` + `webui/app.js`）。直接 merge 会复活 OpenWrt 体系并产生
  200+ 条结构冲突，故按文件逐项搬运。

### 版本与缓存戳

- `src/rust/Cargo.toml` → `2.3.0`；`debian/build-deb.sh` 用
  `sed -n 's/^version[[:space:]]*=[[:space:]]*"\(.*\)"/\1/p'` 单点读取，改一处即生效。
- `MT5700_CSS_VERSION` `2.46.8` → `2.47.0`（`mt5700.css` 本次改动 6000+ 行）。
- `AT_CSS_VERSION` `1.15.1` → `1.15.2`（`at.css` 改动 128 行，缓存戳一并递增，
  否则浏览器会继续命中旧样式）。

### 未验证项（本机无法覆盖）

- deb 安装 / 卸载与 systemd 启停（需实机 `dpkg -i` 与 `systemctl`）。
- 真实 AT 串口交互（需接模组）。
- QQ 机器人真实收发与扫码绑定。
- 浏览器实机 12 视图渲染与窄屏 Tab 悬浮菜单表现。

### 已知缺口（留待后续批次）

- `main` 的 `service.js` 承载 **QQ 推送、定时推送、信号巡检** 等设置入口，
  本分支 `service.js` 为独立实现，这些入口尚未接入。
- `usage_source` / `sms_storage` 在 `main` 上也无前端入口（后端独有键），
  本分支需另行设计入口。
- 后端 `/api/rpc/mt5700/sms` 路由未开放：`rpcserver.rs` 的 `handle_sms` 为私有
  `async fn`，HTTP 层尚需一层公开转发，短信中心相关前端会优雅报错。
- `at-webserver/smsEncode.js` 在 `main` 已删除（编码并入 `rpc.js`），本分支仍保留
  且被 `app.js` 预加载，确认无引用后可清理。
