**白色毛玻璃设计系统落地** —— 全站 12 个 LuCI 页面重构为 White Frosted Glass 风格：动态 SVG 徽标、响应式布局与 100% 汉化；同时模组设置新增 USB 链路速率自动识别、IMEI 四重验证，扫频不再被蜂窝数据卡死。

### 全新 UI 设计系统与全页面重构

- **白色毛玻璃设计系统（White Frosted Glass）**：CSS Backdrop Filters（`blur(24px) saturate(180%)`）+ 半透明白底 + 纳米级白边高光 + 多重弥散阴影，全站科技质感统一。
- **动态 SVG 矢量徽标**：12 个页面各配定制动态 SVG 插画（脉冲呼吸环 / 全向扫描雷达 / 双向数据波 / 量子齿轮旋转 / 微光流溢），支持流畅关键帧动效。
- **全量页面重构**：网络状态 / 网络设置 / 拨号设置 / 全网扫频 / 定时锁频 / 模组设置 / 模组升级 / 短信中心 / 短信设置 / AT 调试终端 / 运行日志 / 服务配置，全部毛玻璃化 + 骨架屏 + 语义配色。
- **响应式深度适配**：手机端（≤580px）单列弹性卡片、触控友好按钮、防溢出滚动；桌面端双列/多列对称布局。
- **全量汉化**：`po/zh_Hans` 与 `po/templates` 翻译字典补齐，界面 100% 优雅中文。

### 模组设置：自动识别 USB 链路速率

- 「模组设置」页新增 **USB 速率** 行与模组 product 名称展示，数据源直读 sysfs（`/sys/bus/usb/devices/*/`），自动识别、不硬编码、不下发任何 AT 命令。
- 新增 `mt5700.usb` RPC 方法（设备侧枚举 USB）+ 前端 `AtWs.usb()` 封装，速率自动格式化为规范名（如 `5.0 Gbps（USB 3.0）`）。

### 5G 状态页：载波聚合卡片重构

- 频谱展示由 SVG 整体缩放重构为**固定字号 HTML 频谱卡片网格**，窄屏不再挤压到不可读。
- 新增聚合总览条（载波数徽章 + 总带宽汇总），多载波场景每载波一张渐变卡片自动并排；射频信号四联仪表盘手机端改 2×2 布局。

### 全网扫频：扫描前自动断开蜂窝数据，结束后自动恢复

- 修复「全网扫频无法使用」：数据业务激活时 `AT^CELLSCAN` 会被模组拒绝（`+CME ERROR: operation not allowed`）。
- 后端扫频任务自动执行「断连 → 扫描 → 恢复」三步，任一路径（成功/失败/超时/取消）都无条件恢复数据连接，拨号对账守护兜底防长期断网。
- 前端扫频前弹窗确认（数据激活时），数据未激活不弹窗直接扫。

### 模组设置：IMEI 独立卡片与四重验证

- IMEI 从设备信息表格拆分为独立卡片「设备标识（IMEI）」。
- 修改改为显式按钮 + **四重验证**：Luhn 校验位验证 → 密文二次输入确认 → 当前 IMEI 后 6 位归属验证（读取失败自动跳过）→ 最终确认弹窗。

### AT 终端：常用命令新增 ICCID / IMSI 查询

- 「常用命令」新增「查询 ICCID」（`AT^ICCID?`）与「查询 IMSI」（`AT+CIMI`）快捷按钮，均为只读查询，点击后二次确认再下发。
