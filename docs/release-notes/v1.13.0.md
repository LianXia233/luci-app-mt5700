**v1.13.0 以「视觉焕新 + 易用性提升」为主**：全站 12 个页面换上白色毛玻璃设计系统；模组设置自动识别 USB 链路速率；全网扫频不再被蜂窝数据卡住（扫前自动断网、扫完自动恢复）；IMEI 修改升级为四重验证，防误操作。

### 全新 UI：白色毛玻璃设计系统

- 全站 12 个 LuCI 页面统一焕新（网络状态 / 网络设置 / 拨号设置 / 全网扫频 / 定时锁频 / 模组设置 / 模组升级 / 短信中心 / 短信设置 / AT 终端 / 运行日志 / 服务配置）。
- 每个页面配专属动态 SVG 徽标：脉冲呼吸环、全向扫描雷达、双向数据波、量子齿轮旋转等动效。
- 深度适配手机端（窄屏单列弹性卡片、触控友好按钮）与桌面端（双列/多列对称布局）。
- 全站汉化补齐，界面 100% 中文。

### 手机端显示优化

- 修复手机端（≤768px）页面标题 SVG 卡片过大的问题：竖排布局下内容区不再被撑成整屏高度，插画区限宽限高（最大 210×96px），实测 375px 视口下卡片高度从 706px 降至约 255px，不再占满整块屏幕。
- 该修复作用于全站 12 个页面共用的 Hero 卡片组件，一处改动全局生效。

### 模组设置：自动识别 USB 链路速率

- 自动识别并展示 USB 链路速率（如 `5.0 Gbps / USB 3.0`）与模组型号，全程不下发 AT 命令、不干扰拨号。

### 5G 状态页：载波聚合卡片重构

- 载波聚合频谱改为固定字号卡片网格，窄屏不再挤压到看不清。
- 新增聚合总览：载波数徽章 + 总带宽汇总；多载波场景每载波一张卡片并排展示。

### 全网扫频：扫描前自动断网、结束后自动恢复

- 修复「全网扫频无法使用」：数据业务激活时模组会拒绝扫频命令（`+CME ERROR: operation not allowed`）。
- 扫描前自动断开蜂窝数据，扫描结束（成功 / 失败 / 超时 / 取消）后无条件恢复，配合拨号对账兜底，不会长期断网。
- 前端扫描前弹窗提醒（数据激活时），数据未激活直接扫。

### 模组设置：IMEI 独立卡片与四重验证

- IMEI 独立成卡，修改需通过 Luhn 校验、二次输入确认、设备归属验证（后 6 位）、最终确认弹窗四重关卡。

### AT 终端：新增 ICCID / IMSI 查询

- 常用命令新增「查询 ICCID」与「查询 IMSI」快捷按钮，只读查询、二次确认后下发。
