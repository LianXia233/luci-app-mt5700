**v2.0.1 为注释与文档质量版**：在 v2.0.0 基础上，对 WebUI 前端与 Rust 后端注释做全量语义校正，并清除指向历史实现、外部工程与旧设计稿的来源性表述，不改动任何代码逻辑、样式规则或 AT 命令流。

### 调整内容

- **docs(comment)**: 注释按代码实际行为逐条校正，并统一为自足表述。
- **docs(webui-js)**: 清理 `webui/` 各 JS/CSS 中的对照字样，包括 `等价迁移原 WebUI xxx.tsx`、`原 WebUI（Semi Design）`、`原前端`、`等价 atx.ts`、`等价原 AutoRefresh`、`等价 modem/*.ts`、`等价 Rust pdu.rs / Go pdu.go`、`carrier.ts / reject.ts / sim.ts 等价迁移`、`node-pdu`、`等价 rpcd log.read` 等；并删除各页面头部的「新 UI 视觉 + 基准 v1.3.4 功能」版本对照说明。
- **docs(webui-js)**：按实际代码校正注释语义：
  - `rpc.js`：`_dirty` 为布尔而非「页面数」、`uciSave` 返回含 `changes`、去掉已不存在的 OpenWrt ubus 状态码历史叙事、认证说明改为 auth_key + 401 弹窗；
  - `mt5700.js`：宽度分档改述为 len-md(0.85×)/len-lg(0.72×)/len-xl(0.62×) 三档、`BAR_COUNT` 明确为 5 档位映射 4 值；
  - `ui.js`：`autoRefresh` 返回值补全 `getInterval/isEnabled`；连接状态卡片说明改为「返回隐藏 div」；
  - `network_status.js`：头部由「三列等高 ~440px」修正为双列栅格 + 末卡跨行；
  - `sms_settings.js`：短信开关关闭步骤由「反向」修正为实际命令序列；
  - `smsEncode.js`：补 3GPP TS 23.040 / 23.038 引用；
  - `logs.js`：去掉对不存在的 `mt5700.uc` 的引用。
- **docs(rust)**：后端注释依代码实际校正：
  - `logger.rs`：输出流实为 stderr（`eprintln!`）；
  - `httpserver.rs`：补 `/ws` 每 30s ping 保活、`/api/service/restart` 为延时退出（非「优雅退出」）、认证边界涵盖 `/ws`；
  - `state.rs`：长命令分支直接返回 Err，回退旧缓存由 `resolve` 处理；
  - `schedule.rs`：`registered` 实际下发 C5GREG / CEREG / CREG；
  - `serialdetect.rs`：去掉 was/now 版本叙事，说明子串匹配的误判风险；
  - `pdu.rs`：补 `unpack_septets` 的 count 语义与 BCD 返回类型；
  - `atclient.rs`：去掉历史叙事，修正钩子路径说明；
  - `at_queue.rs`：`pump` 改为实际方法名 `dispatch`；
  - `config.rs` / `configstore.rs` / `schedconfig.rs`：去掉对 UCI 的溯源表述。
