**样式修复版** —— 修复短信中心（`admin/modem/5g/sms`）在夜间模式下不跟随变色、部分文字在浅底上读不清的问题。亮色样式、间距、字号、布局、圆角、图标与交互全部保持原样，改动只在 `html.at-dark` 下生效。

### 根因

- 短信页是全站唯一一套写死的浅色 palette（`#fff` / `#f2f4f7` / `#f7f9fc` / `#eef2f7`），`mt5700.css` 里同时含 `at-dark` 与 `mt5700-sms` 的选择器数量为 **0**，源码注释也写明它「保持现状、不随 LuCI 主题变量改写」。
- 但夜间模式下主题/插件仍会把继承文字与表单控件改成浅色（`.mt5700-page` 在 `at-dark` 下 `color: #f1f5f9`，输入框变深底浅字），于是页面留在浅色底、文字却是浅色 —— 浅底浅字。
- 实测（ImmortalWrt + Vantage 主题，`ui_mode` 两种模式都复现）：普通模式暗色下搜索框文字 1.10、空状态 2.71、归档弹窗正文 1.07、弹窗标题 1.08；简洁模式（`md3.css`）暗色下搜索框 1.13、页面层文字 1.27、归档行标题 1.15。

夜间模式触发（实机确认，非按主题文档推测）：Vantage 页头内联脚本读 `localStorage['vantage.theme']`（`auto` / `dark` / `light`），在 `<html>` 上写 `data-theme` 与 `data-darkmode`，插件 `theme.js` 再据此打 `html.at-dark`。判据本身是通的，缺的是短信页的暗色规则。界面模式由 `at-webserver.config.ui_mode`（`normal` / `minimal`）决定，落到 `html[data-ui-mode]`。

### 主要改动

- **fix(css) 新增暗色适配一节**：整节以 `html.at-dark` 开头，改写页内语义色（`--sms-text` / `--sms-muted` / `--sms-soft` / `--sms-line` / `--sms-selected` / `--sms-bubble-in`），并逐项覆盖搜索、筛选、会话项、顶栏、气泡、日期条、时间戳、删除键、输入框、字数提示、发送键、空状态。
- **fix(css) 弹窗**：归档 / 批量删除弹窗挂在 `body` 上、不在页壳内，单独补暗色；新短信弹窗（窄屏规则里写死白底）一并改暗。选择器特异性高于 `md3.css` 的 `html[data-ui-mode="minimal"] …`，所以 `normal` 与 `minimal` 读到同一份暗色。
- **fix(css) 按钮对比度**：发送、新短信、确定三处蓝底白字在暗色下改用更深的蓝（`#0b7cb8` / `#0d74ae`），危险键改用 `#d13a50`；白字对比度从 2.3-3.4 提到 4.58 以上。
- **fix(css) hover / focus 态补齐**（PR #47 评审）：原 `.mt5700-sms-shell .mt5700-sms-side-foot .mt5700-btn-primary:hover:not(:disabled)` 带 `!important` 的亮蓝渐变（特异性 0-5-0）会压过无 `:hover` 的暗色规则，把「+ 新短信」的悬停态拉回浅底白字；补 `html.at-dark … :hover:not(:disabled)`（0-6-0）改 `#096fa6`。归档弹窗危险键补 `color:#fff`，否则简洁模式被 `md3.css` 的 `--md-sys-color-on-error` 染成深红字（4.74）；新短信「确定」补暗色 `:hover` 渐变，否则简洁模式悬停回落到 md3 浅紫 `#c4b5fd`（1.85）。
- **fix(css) 占位符与死声明**：三处 `::placeholder` 补 `!important`（原规则带 `!important`，不补则新声明不生效），统一为 `#93a3b5`（暗底 5.48）；`.mt5700-sms-del:hover` 背景补 `!important`，避免成为死规则。
- **chore** `MT5700_CSS_VERSION` 2.46.6 → 2.46.7，`PKG_VERSION` / `MT5700_UI_VERSION` 1.32.3 → 1.32.4。
