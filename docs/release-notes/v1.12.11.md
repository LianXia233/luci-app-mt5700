**升级页也更「看得懂」了** —— FOTA 检测与升级进度从「靠提示气泡连蒙带猜」变成一眼可读的醒目可视化；同时 Rust 后端把状态采集与 AT 调度重构为异步架构，缓解并发抢指令导致的排挤。

### 升级页可视化（业务逻辑保持不动）

- **状态提醒横幅**：发现新版本 / 正在下载 / 下载完成 / 升级中 / 升级失败等关键 FOTA 状态，升级卡底部以「图标 + 标题 + 一句说明 + 语义配色」实时提示。
- **FOTA 状态语义配色**：查询中=蓝、发现新版/下载完成=绿、升级中/下载失败=红、下载挂起=橙，一眼可判当前阶段。
- **进度更直观**：大号数字百分比 + 阶段色进度条（下载=蓝 / 升级=红），随阶段切换颜色。

### 异步架构优化（Rust 后端）

- **状态缓存异步化**：前端每 5s 的只读 AT 查询改读内存缓存毫秒级返回，不排队下发；断开自动清空，页面离开自动停轮询。
- **后台任务统一管理**：引入任务管理器 + 取消令牌，长操作（扫频等）带状态机，取消只发信号、不粗鲁丢弃。
- **AT 命令按优先级调度**：用户终端=High / 状态查询=Normal / 后台缓存=Low / 扫频=Background，High 可越过后台，修复长命令拖死 AT 终端的问题。
