**v1.14.4 为 status 页底部栅格修复版**：在 v1.14.3 基础上，消除 status 页底部双列卡片区的空位与孤行。

### 问题与根因

- **现象**：底部卡片区「中间空缺一块、末尾多出一块孤立卡片」。
- **根因**：`mt-row-2col` 使用 `repeat(auto-fit, minmax(min(100%,460px),1fr))`，桌面宽度下恰好解析为 2 列；而「连接状态 + 辅载波信号遥测 + 连接诊断」「流量统计 + IP 与 DNS + 调制方式与空间流」两组各放 3 张卡 → 第 3 张卡换行，连接诊断右侧留下空位，调制方式与空间流孤行独占，形成「缺卡 + 多卡」的视觉错觉。卡片实际数量（11 张）始终正确。

### 修复

- `mt-row-2col` 改为确定性 2 列 `repeat(2, minmax(0,1fr))`，并新增窄屏（≤900px）降级单列的媒体查询，与「桌面双列、窄屏单列堆叠」设计语义一致。
- 新增奇数末卡横跨规则：`.mt-row-2col > :nth-child(odd):last-child { grid-column: 1 / -1; }`，3 卡行的末卡（连接诊断、调制方式与空间流）自动横跨双列全宽。
- 修复后：实时速率+速率曲线、连接状态+辅载波信号遥测、载波聚合+模组温度、流量统计+IP 与 DNS 两两并排；连接诊断与调制方式与空间流全宽展示，无空位、无重复、均匀对齐，样式与页面整体风格一致。
- 同步更新 `_layout-test/status-mock.html` 布局测试样张。
