**Debian 分支 v1.14.4 为 status 页底部双列栅格消除空位与孤行版**：将 `main` 分支 v1.14.4 的前端改动移植到独立 WebUI。

### 底部双列栅格修复

- 问题现象：底部卡片区「中间缺一块、末尾多一块」。根因是 3 张卡放入 2 列 `auto-fit` 网格后换行，第 3 张卡单独占第二行且只填左列，视觉上形成「空位 + 孤行」的错觉，并非卡片数量错误。
- 修复方式：`.mt-row-2col` 由 `repeat(auto-fit, minmax(min(100%,460px),1fr))` 改为**确定性** `repeat(2, minmax(0, 1fr))`，并新增 `:nth-child(odd):last-child { grid-column: 1 / -1 }` —— 奇数张卡的行由末卡横跨全宽，彻底消除换行空位。
- 窄屏（≤900px）回落单列并复位 `grid-column`，移动端排版不受影响。
- 同步更新静态布局样张 `_layout-test/status-mock.html` 的等价栅格规则。

### 移植说明

- 本次一并将布局回归样张引入 Debian 分支 `webui/_layout-test/status-mock.html`，可在**不接后端、不接模组**的情况下静态预览栅格效果：
  启动服务后访问 `http://<host>:9000/_layout-test/status-mock.html`。
- 样张适配两处：去除 LuCI 专属的 `?v=2.13.0` 资源版本戳（Debian 无 luci.js statics 指纹机制）；补充 Debian 访问路径与「静态占位数据不代表真实状态」的说明。资源引用路径 `/luci-static/resources/...` 与后端 `serve_static()` 的 web_root 解析一致，无需改写。
