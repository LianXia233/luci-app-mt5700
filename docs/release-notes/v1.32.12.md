# v1.32.12 — 工程化收口：i18n、CI 门禁、供应链校验与素材声明

**发布日期**：2026-11-24
**类型**：`工程` `安全` `界面`
**升级方式**：覆盖安装即可，无 UCI / RPC / ACL 接口变更。角色素材继续随包保留；新增的只是包内声明与构建校验。

---

## 为什么做这一版

v1.32.11 之后做了一轮仓库体检，发现四类“不影响功能、但会影响长期维护与分发可信度”的问题：

1. **i18n 名存实亡**：12 个视图里几乎没有 `_()`，语言包只覆盖菜单/旧文案；而发布流程仍单独产出 `luci-i18n-*`。
2. **CI 门禁有缺口**：AGENTS.md 要求 clippy 零告警，但 CI 只跑 `cargo test`；端到端 mock 模组、shell 静态检查都不在门禁里。
3. **构建供应链缺少校验**：rustup 走 `curl | sh`、zig/SDK 下载不校验哈希、Release 资产没有校验和，用户安装只能 `--allow-untrusted`。
4. **文档口径与实现脱节**：README 写“常驻内存仅数十 KiB / 无锁 AT 队列”，与 Tokio 运行时和 `tokio::sync::Mutex` 优先级门的实际实现不符；`websocket_allow_wan` 实际只放行 LAN。

## 主要改动

### i18n

- 恢复 `po/templates/luci-app-mt5700.pot` 与 `po/zh_Hans/luci-app-mt5700.po`，构建重新产出 `luci-i18n-mt5700-zh-cn`。
- `mt5700.js` 新增 `tr()`：页面标题、卡片、按钮、表单标签、输入占位、下拉选项、空态/提示统一经 LuCI `_()`；无 `_()` 的 Node 环境原样返回。
- 清理 po 的重复 msgid、过期文案（旧的“留空监听所有接口”等），补齐当前监听范围、认证密钥提示、页面标题与副标题。
- 新增 `tests/i18n-test.js`：校验 pot/po 集合一致、无重复、zh_Hans msgstr 非空、menu.d 标题全覆盖、共享组件确实接入了 `tr()`。

### CI 门禁

- `checks.yml` 的 `rust-unit` 增加 `cargo clippy --all-targets -- -D warnings`；Rust 工具链版本改由 `src/rust/rust-toolchain.toml` 单一来源读取。
- 新增 `mock-modem-e2e` job：编译 release 后端 + `npm ci` + `run-e2e.sh`，端到端链路进入合并门禁。
- 新增 shell 门禁：`sh -n` 与 `shellcheck -S error` 覆盖 `*.sh` 及带 `#!/bin/sh` / `#!/bin/ash` 的 init.d、hotplug、uci-defaults。
- 修掉现有 2 条生产 clippy 告警与 19 条测试目标告警（`?` 简化、`is_multiple_of`、常量断言、结构体初始化等）。

### 供应链校验

- `src/rust/rust-toolchain.toml` 固定 Rust `1.98.0`，并声明 `clippy` 组件。
- `scripts/sdk-build.sh` 不再 `curl | sh`：下载固定归档版本的 `rustup-init` 1.29.3 并校验官方 SHA256；zig 0.13.0 与 OpenWrt SDK 也校验官方哈希，校验失败直接中止。
- 构建工作流在发布前生成 `SHA256SUMS`，与 apk/ipk/语言包一起上传 Release；README 与 `ARCH-GUIDE.txt` 给出 `sha256sum -c` 校验命令。

### 角色素材

- 按维护者决定，四张背景图与 `mascot.png` **继续保留在界面与安装包内**，不改变现有视觉。
- 新增包内 `/usr/share/licenses/luci-app-mt5700/ARTWORK-NOTICE.txt`：列明两部作品、权利人、无书面授权状态与权利主张渠道。
- README / `THIRD-PARTY-NOTICES.md` 的措辞从“建议移除”改为“按维护者决定保留，若权利人异议则移除或替换”，并保留完整风险披露。

### 文档口径

- README：内存改为“MB 量级、随固件/配置变化”，AT 队列改为“异步互斥 + 优先级队列”。
- 补充 `SHA256SUMS` 校验步骤、i18n 接入说明、CI 门禁命令。
- `main.rs` 启动日志不再硬编码 `127.0.0.1`，改为输出实际监听地址。
- `AGENTS.md` 更新测试基线（377 passed / 2 ignored）、clippy 门禁、i18n 约定与素材声明要求。

## 已知边界

- i18n 目前只把**共享组件**文案接入 `_()`；页面正文仍以中文为源串，新增语言会先覆盖标题/按钮/表单/空态，正文需要后续逐页迁移。
- 角色素材仍无权利人书面授权；保留是产品决策，不构成授权。收到异议将移除或替换。
- 构建产物仍未由 OpenWrt 官方密钥签名，`--allow-untrusted` 仍是安装前提；完整性以 Release 的 `SHA256SUMS` 为准。
