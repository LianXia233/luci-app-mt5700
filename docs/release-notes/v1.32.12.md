# v1.32.12 — 看板娘渲染修复（1.32.11 补丁）

**发布日期**：2026-11-24
**类型**：`修复` `界面`
**基线**：v1.32.11
**升级方式**：覆盖安装即可；无 UCI / RPC / ACL 变更。

## 问题

英雄栏右上角的看板娘头像不显示，`.mt5700-hero-art` 容器宽度始终为 0。

## 根因

`Mt5700.page()` 创建页面节点时，节点还没有被 LuCI 挂到 `document` 上；而
`syncMascots()` 使用的是：

```js
document.querySelectorAll('.mt5700-hero-art')
```

此时它只能看到已经挂载的 DOM，找不到当前这个尚未挂载的页面，所以看板娘从未被插入。
该缺陷在 v1.32.5 引入「普通/极简模式统一钩子」时就已存在，不是 1.32.12 的回退问题。

## 修复

- `syncMascots(root)` 接受可选作用域，缺省回退 `document`。
- `Mt5700.page()` 中改为 `syncMascots(node)`，在页面挂载前直接操作自己的节点。
- 极简模式切换仍由 `bindMode()` 的 `syncMascots()`（document 作用域）处理，行为不变。
- 新增 `tests/mascot-render-test.js`：约束 `syncMascots(root)`、`api.page(node)`、
  `.mt5700-hero-art` 容器与 `mascot.png` 版本戳，防止再次回归。
