**界面交互版** —— 把 `admin/modem/5g` 下的 12 个页签在窄屏（≤768px）收进一个可展开的悬浮菜单，桌面宽屏保持原生一排 Tab 不变。

### 为什么改

- 12 个页签在手机竖屏下会换行成 3 排（360 / 390 宽实测 Tab 条高 108px），既挤占内容区，又把首屏推下去约一屏的六分之一。
- 桌面宽度下一排排布正常，问题只在窄屏。因此改动只针对交互形态，不重做布局、不换配色。

### 主要改动

- **feat(ui) 窄屏悬浮菜单**：`≤768px` 时把原生 Tab 条收起，在原位置挂一个 38px 高的药丸触发器（当前页名 + 页签总数）；点击展开 300px 宽的气泡浮层（`max-height: min(60vh, 420px)`，超出内部滚动），条目按原顺序生成，当前页高亮并带 `aria-current="page"`。
- **feat(ui) 交互口径**：点击触发器展开/再点收起；点击浮层以外任意位置收起；`Esc` 收起并把焦点交还触发器；条目按 DOM 顺序自然进入 `Tab` 焦点链；浮层绝对定位、不参与文档流，页面滚动与底部固定操作栏位置不受影响。
- **feat(ui) 两套结构兼容**：`#tabmenu > ul.tabs / ul.cbi-tabmenu`（bootstrap / material / argon / openwrt-2020）与 ImmortalWrt Vantage 主题的 `nav#vt-tabs > .vt-pagetabs > a.vt-tab`（无 `#tabmenu` 容器，页签名从 href 末段取）。
- **feat(ui) 渐进增强**：只有悬浮菜单构建成功才给 `body` 加 `at-tabmenu-mobile` 并由该类隐藏原生 Tab 条；JS 未执行、主题结构变化或宽度回到桌面时，原生 Tab 条保持可用（不删节点、不改 href）。
- **fix(ui) 顺带修正**：此前 Tab 增强只认 `#tabmenu`，在 Vantage 主题上整段逻辑空转（既不注入图标也不做滚动校正）。现在图标注入仍只作用于 `#tabmenu` 系以保持 Vantage 桌面观感零改动，窄屏悬浮菜单则两套结构都生效。
- **fix(ui) ARIA 语义**（PR #48 评审）：浮层是「触发器 + 链接列表」的展开收起，不是 ARIA menu。容器改为 `role="group"`（保留「页面切换」分组名），条目回归原生链接语义并移出 `role="menuitem"`，触发器去掉 `aria-haspopup`，只保留 `aria-expanded` / `aria-controls`。
- **style(css)** 沿用插件既有变量（`--mt5700-float-bg` / `--mt5700-glass` / `--mt5700-accent-pale` / `--mt5700-sh-float`），亮色与 `html.at-dark` 暗色均无新增色值。
- **chore** `MT5700_CSS_VERSION` 2.46.7 → 2.46.8，`PKG_VERSION` / `MT5700_UI_VERSION` 1.32.4 → 1.32.5。
