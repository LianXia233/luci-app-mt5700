**移动端排版优化版** —— 邻区扫描与 PDP 上下文表格在手机端改为两列网格堆叠卡，彻底消除横向滚动与堆叠错位；空态双角色立绘整体移除，空态更轻更聚焦。

### 主要改动

- **多列表格移动端两列网格堆叠**：网络设置·邻区扫描（8 列）与拨号设置·PDP 上下文（5 列）在 ≤768px 改为两列网格堆叠卡——邻区按「制式|频段 / ARFCN|PCI / RSRP|RSRQ / SINR|操作」、PDP 按「CID|协议 / APN|状态 / 操作整行」排布；实测邻区单卡 370→139px（−62%）、行高 44→28px，三视口零溢出。此前手机端行高被全局样式的 `!important` 顶回桌面尺寸，一屏只能看 1.5 个邻区。
- **拨号页 PDP 表格视图去横滚**：删除手机端 `min-width:620px` 强制横滚；固定列宽只在桌面端（≥769px）生效，不再污染堆叠布局；PDP 卡片操作按钮一行三等分。
- **邻区空数据去重**：无邻区时只渲染空态组件，不再同时画「暂无数据」表格行造成双重占位。
- **移除空态双角色立绘**：`api.empty` 只保留空态文案，两段约 1300 行的立绘 SVG 源码常量与配套舞台/定位壳/漂浮动画样式全部删除（15 处空态调用点行为不变）。
- **`api.table` 新增 `options.className`**：调用方可为表格追加专类供定向样式命中，向后兼容。

### 验证记录

实机（192.168.88.1，ImmortalWRT）热更新 5 个前端文件（md5 校验一致）后浏览器实测：390px 邻区卡 139px / 零溢出、700px 网格堆叠生效、1280px 真实表格与 PDP 固定列宽 [70/120/自适应/90/190] 保持不变；PDP 表格视图手机端零横向滚动。`tests/static-check.js` 4/4、全部零依赖单元测试通过。
