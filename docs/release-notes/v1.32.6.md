**日志可观测性版** —— 日志按 21 个类别三路分流：软件自身的运行时日志照旧进 syslog，模组业务痕迹（AT 收发、短信正文、拨号过程等）只进内存环形缓冲与插件自有文件，重启后仍能查到。

### 为什么改

- 改动前所有日志只有一条路：先入内存环形缓冲，再按级别 `eprintln!` 到 stderr，由 procd/logd 收进 syslog。结果 `logread` 里混满 AT 收发原文与短信正文（既刷屏又含隐私），而真正需要跨重启留存的业务痕迹反而留不住 —— 环形缓冲一满就被挤掉，后端被 procd 拉起后什么都查不到。
- 稳态全局级别是 `Warn`，如果连环形缓冲也按级别过滤，排障最需要的 info 级拨号与接口过程会整段消失。因此缓冲不再看级别，只按类别分区。

### 主要改动

- **feat(log) 21 个类别**：运行时组 7 类（`RT` `CFG` `RPC` `TTY` `TSK` `STO` `MISC`）、业务组 14 类（`AT` `URC` `DIAL` `NET` `SIG` `SIM` `SMS` `CALL` `NTF` `SCAN` `SCH` `FOTA` `USAGE` `TIME`）。类别目录集中在新增的 `src/rust/src/logcat.rs`，每类自带小写稳定键、行内短标签、分组、是否落盘、syslog 地板，分流策略不散落到各业务模块。
- **feat(log) 零成本接入**：日志宏支持可选首参 `Cat::Xxx`，未显式指定时按编译期 `module_path!()` 推导模块归属。238 处调用点里只有跨业务域的 98 处需要手动标注。
- **feat(log) 三路分流**：全部日志无条件入环形缓冲（1200 条 / 512 KiB 双上限）；业务类另写 `/tmp/at-webserver/plugin.log`（有界追加、只按行边界裁剪、落 tmpfs 不磨闪存），多行消息落盘前压平成单行；syslog 侧由「类别地板 + 全局级别」两道闸门把关，业务类只有 `ERR` 破例仍发 syslog，免得 `logread` 里连「短信发送失败」都看不到。
- **feat(log) 落点可配**：UCI 新增 `log_plugin_file_enabled` / `log_plugin_file` / `log_plugin_max_bytes`，默认值已写进 `root/etc/config/at-webserver`。上限低于 4096 或路径为空时回落默认；目录创建失败只降级为「不写文件」，不影响另外两个去处。
- **feat(log) `logs` RPC 支持 `cats`**：字符串 `"sms,at"` 或数组都收，非法键丢弃。未传 / 空串 / 空数组 = 不过滤；传了内容但全是非法键 = 筛过了但零命中 → 空结果。SSH 里 `ubus call mt5700 logs '{"cats":"sms"}'` 即可只看短信链路。
- **fix(log) 插件文件行带绝对毫秒**：行格式为 `2026-11-08 04:40:01.123 (1762555201123) [INF] [SMS] 正文`。行首文本是路由本地时区、不带偏移，浏览器按自己的时区解释会让整批文件条目平移、并与内存条目的去重键对不上，页面显示成两条。前端有 epoch 一律用 epoch，旧格式才退回逐字段重建，`Date.parse` 仍然不用。
- **feat(ui) 日志页三源合并**：「插件文件」作为第三路来源（读文件排在 RPC 之后，路径只随 RPC 下发）；类别筛选条由 7 项扩到 22 项（`全部` + 21 类），按「软件运行 / 业务痕迹」两段渲染；合并去重键为 `ts + '|' + 正文`，重启前只存在于文件里的历史照常保留；页脚显示业务日志文件路径与上限，导出文本每行带 `[CODE]` 段。
- **style(css)**：21 类徽章明暗两套共 42 条规则，新增来源徽章与分组条样式；`≤768px` 类别条改为单行横向滚动，避免 22 个 chip 在竖屏堆成三四排。`MT5700_CSS_VERSION` 2.46.8 → 2.46.9。
- **chore** `PKG_VERSION` / `MT5700_UI_VERSION` 1.32.5 → 1.32.6。

### 升级提示

- 覆盖安装即可，无配置迁移。`MT5700_UI_VERSION` 1.32.5 → 1.32.6，浏览器模块缓存整体失效；`MT5700_CSS_VERSION` 同时由 2.46.8 升到 2.46.9，样式表会重新拉取。
- 业务类日志默认不再进 syslog（只有 `ERR` 破例）。要看全量请用页面「插件文件」来源，或 `ubus call mt5700 logs`。分流规则刻意不做成配置项：能把它灌回 syslog 的开关等于把这次改造关掉。
- 行为变更：`logs` RPC 的 `cats` 全填非法键时现在返回空结果（以前会静默返回全部）。页面的类别筛选是前端本地过滤，不受影响。
- 升级前已写入 `/tmp/at-webserver/plugin.log` 的旧格式行（没有括号内毫秒）仍能解析，只是退回按浏览器本地时间解释，与修复前行为一致；清空该文件或重启后即彻底消失。
