**v1.14.3 为全页面移除「AT 服务在线」连接状态卡片版**：在 v1.14.2 基础上，按需求将 AT 服务连接状态卡片从所有页面移除。

### 移除连接状态卡片

- 移除对象：`at-status-card` 状态卡片（标题「AT 服务在线 / 正在连接 AT 服务 / AT 服务离线」，副标题「AT 通信服务运行正常」等，右侧 RPC 地址芯片）。
- **页面级移除**：删除全部 10 个 LuCI 页面 render 中的 `connBar` 容器创建与 `Mt5700.renderConnectionBar()` 调用：
  `dial` / `modem_settings` / `network_settings` / `network_status` / `scan` / `schedule` / `sms_center` / `sms_settings` / `terminal` / `upgrade`。
- **实现级兜底**：`mt5700.js` 与 `ui.js` 中的 `renderConnectionBar` 统一改为空操作 stub（返回 `display:none` 占位节点），任何调用均不再渲染任何内容，确保任何页面（含潜在动态调用路径）都不再显示该卡片。
- AT 服务 WebSocket 连接逻辑本身不受影响，仅前端展示层移除该卡片。
