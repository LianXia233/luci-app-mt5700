**Debian 分支 v1.14.3 为全页面移除「AT 服务在线」连接状态卡片版**：将 `main` 分支 v1.14.3 的前端改动移植到独立 WebUI。在 v1.14.2 基础上，按需求将 AT 服务连接状态卡片从所有页面移除。

### 移除连接状态卡片

- 移除对象：`at-status-card` 状态卡片（标题「AT 服务在线 / 正在连接 AT 服务 / AT 服务离线」，副标题「AT 通信服务运行正常」等，右侧 RPC 地址芯片）。
- **页面级移除**：删除全部 10 个视图 render 中的 `connBar` 容器创建与 `Mt5700.renderConnectionBar()` 调用：
  `dial` / `modem_settings` / `network_settings` / `network_status` / `scan` / `schedule` / `sms_center` / `sms_settings` / `terminal` / `upgrade`。
- **实现级兜底**：`at-webserver/mt5700.js` 与 `at-webserver/ui.js` 中的 `renderConnectionBar` 统一改为空操作 stub（返回 `display:none` 占位节点），任何调用均不再渲染任何内容，确保任何页面（含潜在动态调用路径）都不再显示该卡片。
- 连接逻辑本身不受影响（Debian 侧为 `rpc.js` 的 HTTP API 增量轮询 + 后端事件总线），仅前端展示层移除该卡片。

### 移植说明

- 改动直接落在 `webui/luci-static/resources/**`。本分支 WebUI 由 `debian/install.sh` 整体复制到 `/usr/share/mt5700/webui` 并由后端 `serve_static()` 托管，**无需打包、无需构建**，改动随下次 `install.sh` 部署即生效。
- 本分支 `rpc.js`（HTTP API 传输层）与 `service.js`（systemd 服务配置页）为 Debian 独立实现，**未被本次改动触及**，AT 通道与事件推送行为保持原样。
