# v1.22.0

**主题**：签约速率改用厂商命令 `AT^DSAMBR`（4G 也能显示）；修正制式角标写死 5G；核对流量统计数据源。

## 1. 签约速率：4G 也能显示了

v1.21.x 用的是标准命令 `AT+C5GQOSRDP`，**5G 下能拿到 Session-AMBR，4G 下只回空值**（本固件所有 EPS QoS 命令均返回 ERROR）。

翻模组手册第 16 章私有接口，找到 **16.17 `AT^DSAMBR` — 签约速率查询**：

```
AT^DSAMBR=<cid>
<CR><LF>^DSAMBR: <cid>,<DlApnAmbr>,<UlApnAmbr><CR><LF>OK
<DlApnAmbr> 下行签约速率，单位 kbps
<UlApnAmbr> 上行签约速率，单位 kbps
```

实测（实机返回比手册多两个字段 `<APN>,<状态>`）：

| 制式 | 响应 |
|:--|:--|
| 5G (SA) | `^DSAMBR: 1,<dl>,<ul>,"<APN>",<n>` |
| 4G (LTE) | `^DSAMBR: 1,<dl>,<ul>,"<APN>",<n>` |

**4G 与 5G 都能取到真实签约速率。**

取值策略（优先级从高到低）：

1. `AT^DSAMBR=<数据通道CID>` —— 厂商命令，4G/5G 均可用，**首选**；
2. `AT+C5GQOSRDP=<数据通道CID>` —— 标准命令 Session-AMBR，仅作兜底；
3. 两者都取不到 → 显示「模组未上报」，不用其它参数编造。

CID 一律取 `pickDataContext()` 选出的**数据上网上下文**（该函数已剔除 IMS / 紧急 / MMS / SUPL 等专用承载），绝不查 IMS。

`parseDsambr` 只按**前三个位置**取值，后面多出来的 APN / 状态字段原样保留在 `raw` 里，不做臆测。

## 2. 制式角标不再写死 5G

信号强度卡片右上角角标原来是硬编码的 `5G`，**4G 下也显示 5G**，与真实制式不符。

现改为与当前驻网制式同源：

| 制式 | 角标 |
|:--|:--|
| NR | `5G` |
| LTE | `4G` |
| WCDMA | `3G` |
| GSM | `2G` |
| 取不到 | `—` |

实测（通过 `AT^SYSCFGEX` 临时切到仅 4G 注册到 LTE 后验证，结束已切回 5G 优先）：

| 制式 | 角标 | 签约速率 |
|:--|:--|:--|
| 4G (LTE) | `4G` | 正常显示 |
| 5G (SA) | `5G` | 正常显示 |

## 3. 流量统计数据源核对

用户要求核对流量统计是否真实。做法：**独立读取内核计数器**，与页面在同一时间窗内对比增量。

- `netrate` 自动识别的承载网卡：**eth2**（模组上网口）
- 约 26 秒时间窗：

| 对比项 | 与页面差值 |
|:--|--:|
| eth2 内核计数器（模组上网口） | **0.30%** ✅ |
| eth0（LAN 口，未采用） | 三个数量级 ❌ |

0.30% 的残差来自页面 1 秒的采样粒度（页面快照比内核读取最多晚 1s）。**结论：流量统计取的是模组上网口的真实内核计数器，没有编造。**
