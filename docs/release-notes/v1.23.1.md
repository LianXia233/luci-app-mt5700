# v1.23.1

**主题**：修复流量统计「自动清零」天数输入框数字被遮挡；清理前端冗余样式（CSS -528 行，渲染零差异回归）。

## 1. 为什么改：输入框里的数字「看不见」

v1.23.0 上线「自动清零」后，有反馈：在流量卡片「自动清零」一栏的天数输入框里输入数字，
显示不全 —— 只能看到第一位，后面几位像是被什么盖住了。

排查链路：

1. `.mt-usage-days` 自己写的是 `width: 58px; padding: 1px 6px; font-size: 12px`，按这个算，
   4 位数字（上限 3650）应该刚好放得下；
2. 但实际渲染时 `getComputedStyle` 给出的是 `padding: 14px`、`font-size: 13.5px` ——
   这两个值来自文件后段的**全局深度美化规则**：

   ```css
   .mt5700-input, .cbi-input-text, input[type="text"], input[type="password"],
   input[type="number"], input[type="search"], textarea {
     padding: 8px 14px !important;
     font-size: 13.5px !important;
     box-sizing: border-box !important;
   }
   ```

   `!important` + 后出现，把 `.mt-usage-days`（无 `!important`）的 padding / 字号全部顶掉；
3. 于是 58px 宽的框（`border-box`）减去左右各 14px 内边距、1.5px×2 描边后，
   内容区只剩约 27px，而 4 位等宽数字需要约 40px —— **文字溢出被裁**；
4. 再叠加 `input[type="number"]` 自带的步进箭头（spinner，Chrome hover/focus 时显示、
   Firefox 常显），箭头正好压在右对齐的数字上，遮挡雪上加霜。

实测数据（Playwright + Chromium，输入 `3650`）：

| 指标 | 修复前 | 修复后 |
|:--|:--|:--|
| 实际 padding | 14px / 14px（被全局规则顶掉） | 8px / 8px |
| 实际字号 | 13.5px（被顶掉） | 12.5px |
| 对齐 | 右对齐（贴着 spinner） | 居中 |
| spinner | 显示（`appearance: auto`） | 隐藏（`appearance: textfield`） |
| `scrollWidth` vs `clientWidth` | **76 > 56（裁切）** | **70 = 70（无裁切）** |

## 2. 怎么修的

给输入框换用更高特异性选择器 `.mt-usage-cell.auto .mt-usage-auto .mt-usage-days`
并以 `!important` 拿回尺寸控制权：

- 宽 72px（`min-width` + `flex: 0 0 72px` 双保险，不会被 flex 压缩）；
- `padding: 2px 8px`、字号 12.5px、等宽数字（`font-variant-numeric: tabular-nums`）；
- **隐藏步进箭头**（`appearance: textfield` + `::-webkit-inner/outer-spin-button`），
  键盘 ↑/↓ 与手动输入仍然可用，移动端数字键盘不受影响；
- 对齐改为**居中** —— 即使个别浏览器仍渲染箭头，也不会压在数字上；
- 聚焦态补了淡紫描边 + 光晕，与整站输入框观感一致。

## 3. 冗余样式清理（顺带）

按用户要求对 LuCI 前端做了一次冗余代码排查（后端 Rust / ucode 一行未动）。
方法：静态审计 mt5700.css / at.css 中每个类名，与全部 JS / ucode / 模板源码做
出现性比对，并识别 `'前缀-' + var` 动态拼接（避免把 `mt5700-btn-*`、
`mt5700-badge-*`、`mt5700-toast-*` 等动态类误判为死代码）。

删除内容（全部为「零引用」确认后移除）：

| 类别 | 数量 | 说明 |
|:--|:--|:--|
| 死类规则块 | 64 块 | 旧版 `mt5700-*` 仪表盘 / verdict / gauge / skeleton / spinner / 裸 `modal-*` / `temp-*` 温度着色体系等 |
| 被完全覆盖的重复声明块 | 24 块 | 同选择器且属性键被后续块完全覆盖，删除不影响层叠结果 |
| 孤儿 `@keyframes` | 9 块 | 随死类一起失效的动画定义 |
| 孤儿设计令牌 | 6 个 | `--mt5700-temp-*` 温度色板变量 |
| at.css 死类块 | 3 块 | `at-chip` / `at-chip-del` / `at-modal-text` |

`mt5700.css` **5447 → 4919 行（-528 行）**。保留项：`cbi-*`（LuCI 框架生成）、
`.dark-theme` 前缀规则（主题上下文）、`mt5700-btn/badge/toast/log*` 动态系列。

## 4. 怎么验的

- **排版回归**：以 `docs/layout-test/status-mock.html` 为基准页，在 380 / 768 / 1024 /
  1440 / 1920px 五档视口下对「清理前 vs 清理后」做全页截图像素对比 ——
  **五档差异像素数均为 0**，排版零变化；
- **输入框**：见上表，裁切消除；
- **语法**：清理后 CSS 括号配平校验通过，`@keyframes` / CSS 变量无孤儿残留。

## 5. 升级注意

- 样式版本 `MT5700_CSS_VERSION` → `2.23.1`、`AT_CSS_VERSION` → `1.11.1`，
  升级后浏览器强刷（或等缓存自然过期）即可生效；
- 仅前端样式与文档改动，**不涉及后端 / ucode / 配置格式**，可原地覆盖升级。
