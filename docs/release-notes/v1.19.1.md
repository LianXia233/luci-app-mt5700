# v1.19.1

**主题**：修复手机端信号趋势图"必须长按才能看数据"的问题。

补丁小版本，只改信号趋势图的触摸交互。

## 问题

v1.19.0 把悬浮查看改成 pointer 事件后，触摸逻辑是：

```
pointerdown → 显示
pointerup   → 立即收起
```

于是**单击只能闪一下**，想持续看某个点的读数就得一直按住；而长按又会触发系统的文本选中 / 长按菜单，和取数交互互相打架。

## 修复

改成"点击常显"的移动端标准交互：

- **单击常显**：点一下数据点即固定显示读数，松开后不收起。
- **拖动移动**：按住拖动可在点位间连续切换。
- **收起方式**：再次点击**同一个点**收起；或点击**图表以外**的区域收起。
- **跨重绘保持**：历史每 5 秒重绘会重建 SVG，现按**时间戳**恢复上次选中的点，悬浮卡不会每 5 秒闪没。
- **屏蔽长按干扰**：命中区 `contextmenu` 预防；图表容器加 `user-select:none`、`-webkit-touch-callout:none`、透明点按高亮。

桌面鼠标行为不变：悬浮显示、移出收起。

## 实机验证（360px 触摸）

| 操作 | 结果 |
|:--|:--|
| 单击数据点 | 悬浮卡常显（`display:block`，时间 `11:04:47`） |
| 等待 6.5 秒（跨一次重绘） | 仍常显，选中点不变 |
| 再次单击同一点 | 收起（`display:none`） |
| 单击另一个点 | 常显，切换到该点（时间 `11:04:42`） |
