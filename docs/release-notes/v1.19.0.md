# v1.19.0

**主题**：信号趋势图表全面重做（真实性 / 形态 / 交互 / 移动端）。

小版本特性更新，集中在「网络状态」页的 **信号趋势** 卡片。

## 背景

旧图表存在一处**数据不诚实**：首次采样时用 `curR ± 2`、`curS ± 1` 之类偏移**合成** 5 个"历史点"，让曲线一打开就"好看"。这会在没有任何历史的情况下，展示一条设备从未产生过的曲线。

## 变更

### 1. 数据诚实（不再伪造基线）

- 只累积设备真实采样，每 5 秒一个点，最多 30 点。
- 缺读数在历史里写 `null`，绘图**分段**处理：缺口处曲线如实断开。
- 孤立采样点（两侧都是缺口）补绘一个小圆点，避免该采样在图上"消失"。

### 2. 可视化重做

- 保留双 Y 轴：左轴 RSRP（面积 + 主曲线）、右轴 SINR、RSRQ 细虚线。
- 质量分区带更柔和，右侧标注档位（极佳 / 良好 / 一般 / 较差）。
- 末端采样点改为**呼吸脉冲点**，直观标记"当前"。
- 配色统一为 Soft-Anime 柔和调色。

### 3. 交互升级

- **图例可点选**：点一下 RSRP / SINR / RSRQ 即显隐对应曲线（曲线、端点、悬浮点、悬浮卡行同步变化）。
- **范围切换**：`15点` / `30点`。
- **顶部读数条**：实时 RSRP / SINR / RSRQ 大字读数 + 采样进度；被隐藏的序列在读数条中弱化显示。

### 4. 触摸支持

- 悬浮查看改用 **pointer 事件**，鼠标悬浮与手机触摸拖动共用逻辑。
- 命中区 `touch-action:none`：拖动查看数据点不会误触页面滚动。
- 悬浮卡只列出当前可见序列，高度随可见数量自适应。

### 5. 移动端

- 窄屏图高 300 → 320，刻度与悬浮字号加大。
- 时间轴先前在窄屏被截成 `时:分`，同一分钟内多点会显示成三条一模一样的标签，现**一律保留到秒**。

## 实机验证（192.168.88.1）

| 检查项 | 结果 |
|:--|:--|
| 桌面图渲染 | SVG 正常，3 条曲线 + 3 个脉冲端点 |
| 点掉 SINR 图例 | 曲线由 3 条降为 2 条，端点由 3 降为 2，悬浮卡同步隐藏该行 |
| 切换 15 点 | 范围按钮激活态正确切换 |
| 鼠标悬浮 | 十字准星 + 数据卡显示，读数与时间正确 |
| 360px 宽 | 图宽 300、图高 253，读数条与图例换行正常 |
| 时间轴 | `10:54:20 / 10:54:35 / 10:54:45` 三段互不重复 |
