**v1.14.6 为「系统控制」界面重构与分级确认版**：在 v1.14.5 基础上，优化模组设置页「系统控制」区域的按钮排版与高危操作确认流程。

### 排版重构

- 两项操作由单行按钮组改为「信息 + 按钮」双栏操作条：
  - 左侧：色点标识 + 操作名称 + 风险说明（重启注明中断时长；恢复出厂注明清空范围与 3 次确认要求）。
  - 右侧：固定 128px 最小宽度按钮，对齐统一。
- 视觉分级：「重启模组」= 琥珀色警戒级（新增 `mt5700-btn-warn` 描边按钮变体）；「恢复出厂设置」= 红色危险级。操作条底色与描边随风险等级渐变区分。

### 确认流程

- **重启模组**：1 次确认弹窗（含中断时长说明）→ 确认后下发 `AT^RESET`。
- **恢复出厂设置**：连续 3 次警告弹窗（配置清空 → 断网后果 → 最终高危确认，按钮文案带步骤计数）→ 全部确认后才下发 `AT&F`；任一步「取消」即中止且不下发任何命令。

### 安全边界

- 本次改动仅涉及前端 UI 展示与弹窗交互逻辑；AT 命令下发代码路径未变更，页面加载与测试过程中不会自动触发任何重启/恢复出厂命令。
