# v1.18.2

**主题**：修复移动端英雄区看板娘排版 —— v1.18.1 的样式在压缩产物里被旧规则反超，实机未生效。

补丁小版本，只改移动端英雄卡片这一处样式。

## 问题

v1.18.1 把「左文右娘」的移动端排版写在样式文件末尾，本地预览正常；但**打包压缩后的 CSS 会合并/重排多个 `@media (max-width: 768px)` 块**，源码里「在文件末尾」不再等于「在产物里最后生效」。

结果：更早的一条 `.mt5700-hero-art { width: 100% !important; flex-wrap: wrap !important }` 被排到了修复块之后并反超 —— 看板娘占满整行、文案列被压成 **0 宽**（标题竖排成一列），英雄卡片在 360px 窄屏下高达 **443px**。

## 修复

修复块改用**重复类名提高权重**（如 `.mt5700-hero-card.mt5700-hero-card`、`.mt5700-hero-art.mt5700-hero-art`），以特异性稳定压过同 `!important` 的旧规则，不再依赖压缩器保留源码顺序；同时给文案列与看板娘容器补 `min-width: 0`。

## 实机验证（360px 视口）

| 指标 | 修复前 | 修复后 |
|:--|:--|:--|
| 英雄卡片高度 | 443px | **133px** |
| 文案列宽度 | 0px | **211px** |
| 看板娘占用宽度 | 296px | **75px**（贴右居中） |

## 升级

```sh
apk add --allow-untrusted ./<ARCH>-luci-app-mt5700-1.18.2-r1.apk
# 或
opkg install ./<ARCH>-luci-app-mt5700_1.18.2_<ARCH>.ipk
```

升级后若手机端仍显示旧样式，请对页面做一次强制刷新（清掉旧的样式缓存）。

> v1.18.1 的「深度网络诊断上行发射功率」修复（`AT^NTXPOWER`）不受影响，本版仅追加样式修复。
