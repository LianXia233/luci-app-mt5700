**v1.14.1 为 status 页排版紧凑化与手机端修复版**：在 v1.14.0 基础上针对「网络状态」页优化卡片排列，并修复手机端宽表格撑破卡片导致的裁剪问题。

### status 页排版紧凑化

- 「连接状态 + 辅载波信号遥测 + 连接诊断」由双列 + 全宽结构重组为 **3 列并排**，提升桌面空间利用率。
- 「载波聚合」与「模组温度」由全宽大卡重组为 **2 列并排**；「流量统计 + IP 与 DNS + 调制方式与空间流」3 列紧凑并排。
- 「射频信号质量」「实时速率」「速率曲线」三张卡片保持原有全宽 / 双列布局不变。
- 3 列网格响应式降级：1180px 以下降为 2 列、760px 以下单列堆叠。

### 手机端溢出修复

- 网格子项补 `min-width: 0`：手机端「载波聚合 / 辅载波信号遥测」的宽表格不再撑破卡片、被卡片 `overflow: hidden` 裁剪，改为卡片内横向滚动，页面不再水平溢出。
