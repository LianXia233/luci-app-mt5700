# v1.23.0

**主题**：使用量统计改由**后端常驻累计**；新增自动清零（默认 30 天）；清零连记录文件一起清；限制记录文件大小。

## 1. 为什么改：原来只有前端打开才累计

v1.20.0 把累加逻辑放在了 rpcd 的 ucode 插件（`netrateCall`）里，由前端
`setInterval(sampleRate, 1000)` 每秒触发。实测结论是：

- 页面开着 → 正常累加；
- 页面关着 → **没有任何调用，累加动作不发生**；
- 但重新打开时，因为内核计数器 `rx_bytes`/`tx_bytes` 是单调累计值，会把关闭期间的
  增量一次性补记回来（实机关闭页面 30 秒的下载流量，重开后使用量显示值与同期内核增量
  仅差约 1%，残差为页面 1 秒采样粒度）。

也就是说「结果」勉强对，但「语义」是「前端打开才记录」，而且有个真实漏洞：
**关闭期间接口计数器归零（接口 flap / 重新拨号）时，那一段增量直接丢失。**

本次把统计整体挪进 Rust 后端常驻进程，1 秒一采独立累加，与前端是否打开、是否刷新完全无关。

## 2. 新增模块 `src/rust/src/usage.rs`

```
UsageTracker
  ├─ run(ctx)          常驻采样循环（1s），可被关闭信号打断
  ├─ sample()          读计数器 → 到期自动清零 → 累加 → 落盘
  ├─ snapshot()        供 RPC 返回的快照
  ├─ reset()           清零（强制重写/删除两个文件）
  ├─ set_persist()     开关持久化
  └─ set_auto_reset_days()  改自动清零天数（写 UCI + 热更新）
```

前端侧的变化：

- `netrate` RPC **恢复为纯计数器读取**，不再累加任何东西；
- 新增 `usage` RPC（只读快照）+ `usage_ctl` RPC（`reset` / `persist_on` / `persist_off` / `set_auto_reset_days`），由 ucode 代理到 Rust；
- 前端单独一条 1 秒轮询线拉快照，与速率线解耦。

### 承载网卡探测

Rust 侧重实现了同口径的探测链（与 init.d / ucode 一致）：

1. UCI `at-webserver.config.iface_v4` 指定了接口 → `network.<接口>.device`
2. sysfs 上挂在 USB 总线上的网卡（跳过 `lo` / `br-*`）
3. `network.MT5700M` 的 device
4. 兜底 `eth2`

网卡读不到计数（接口 down / 换口）时清掉缓存，下一轮重新探测。

## 3. 清零按钮：连文件一起清

原实现里，清零只是把内存态置零后按节流写盘 —— 持久化开着时，闪存里的旧文件可能
几分钟内都不会被重写，这期间重启会读回旧值。

现在 `reset()` **强制**落盘：

| 持久化开关 | 清零时的动作 |
|:--|:--|
| 开 | 内存态置零 + 重写 `/tmp` 状态文件 + **重写 `/etc` 落盘文件（一并清零）** |
| 关 | 内存态置零 + 重写 `/tmp` 状态文件 + **删除 `/etc` 落盘文件** |

同时把基线重置为当前计数器，避免清零后的第一笔增量把清零前的流量又记回来。

## 4. 限制统计记录文件大小

状态文件是定长 schema 的 JSON，正常只有两百多字节。新增 `MAX_USAGE_FILE_BYTES = 4096`：

- **写入时**：序列化结果超限就放弃本次落盘并记警告 —— 宁可不写，也不写出一个异常大的文件；
- **读取时**：文件大小超限一律视为损坏，忽略并从零开始 —— 绝不把来路不明的大文件读进内存。

## 5. 自动清零（默认 30 天，可自行修改）

新增 UCI 键 `usage_auto_reset_days`，**默认 30 天**，范围 1~3650。

放在 UCI 而不是使用量状态文件里：状态文件在「持久化关」时重启即失，设置跟着一起丢
会让用户每次重启后都要重填。

到期后由后端自行清零并重新基线，**不需要前端参与**（前端关着也一样会清零）。

流量统计卡片新增一行「自动清零」：天数输入框（1~3650）+ 保存按钮，保存即写 UCI 并热生效。

## 6. 边界处理（与旧实现一致，另有单测钉住）

| 情况 | 行为 |
|:--|:--|
| 计数器归零（接口 flap / 重拨） | 只重置基线、**不累加**，避免把一次归零误记成巨额流量 |
| 承载网卡变更 | 只重置基线，累计值保留 |
| 首次采样 | 只建立基线，不累加 |
| 采样间隔异常拉长 | 跳过峰值计算（不把长时间的低均值当峰值），但用量仍如实累加 |
