# v1.18.1

**主题**：修复「深度网络诊断」上行发射功率在 5G 下不显示，并优化手机端英雄区看板娘排版。

一个补丁小版本，两处修复，均已实机部署验收。

## 修复：上行发射功率 (PUSCH / PUCCH) 恒为「—」

网络状态页「深度网络诊断」里的**上行发射功率**此前在 5G 下始终是占位符「—」。

原因：诊断只下发 `AT^TXPOWER?`，而这条命令**只在 GUL（2G/3G/4G）下有效**。当模组注册在 NR（5G）时，模组会直接返回 `ERROR`，解析结果为空，界面就只能显示「—」。NR 的发射功率需要用另一条命令 **`AT^NTXPOWER?`** 查询。

修复后：

- 诊断先查 `AT^TXPOWER?`，再查 `AT^NTXPOWER?`；渲染时**优先用 NR 读数，取不到再回退 GUL**（纯 LTE 场景仍可用）。
- 支持 NR **多载波**（最多 4 个），多载波时按「载波 N PUSCH / PUCCH」并列显示；无效值 `999` 显示为「—」。

实机验证（NR 单载波）：`AT^NTXPOWER?` 返回 `^NTXPOWER: 22,-13,25,-18,2565000`，页面显示 `22 dBm / -13 dBm`，PUCCH 数值随调度实时变化。

## 优化：手机端英雄区看板娘排版

窄屏（≤768px）下英雄卡片原本是上下排（column）：看板娘被推到右下角、左侧留出大片空白、卡片被撑高。现改为**左文右娘**的行布局——文字占满左侧并自动换行，看板娘在右侧垂直居中，标题/描述字号同步收敛。卡片高度从约 233px 回落到约 129px。

## 升级

```sh
apk add --allow-untrusted ./<ARCH>-luci-app-mt5700-1.18.1-r1.apk
# 或
opkg install ./<ARCH>-luci-app-mt5700_1.18.1_<ARCH>.ipk
```

升级后若页面上发射功率仍显示「—」，请在手机上对页面做一次强制刷新（清掉旧的样式/脚本缓存）。

## 验证

- `node tests/parse-regression-test.js` **21/21 通过**（新增 6 项发射功率用例）。
- 实机热部署后 Playwright 验收：诊断行显示实时 PUSCH / PUCCH；看板娘在 320 / 360 / 390 / 768 四档窄屏排版正常。
