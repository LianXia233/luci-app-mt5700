**v1.14.0 为 v1.13.0 的重新编译版**：代码与 v1.13.0 保持一致，包含白色毛玻璃设计系统、手机端显示优化、全站排版紧凑化与相关卡片双列并排等全部特性，本轮仅清理历史 Release 并重新构建发布，确保产出的 apk/ipk 与当前 main 分支完全对应。

### 包含 v1.13.0 全部特性

- 全新 UI：白色毛玻璃设计系统（全站 12 个页面 + 动态 SVG 徽标 + 全站汉化）。
- 手机端显示优化：Hero 标题卡片不再占满整屏，375px 视口下实测高度由 706px 降至约 255px。
- 页面排版紧凑化：全站卡片间距与内边距统一收紧；网络设置 / 模组设置 / 短信设置 / AT 终端 / 服务配置的相关卡片桌面端双列并排，手机端保持单列堆叠。
- 模组设置自动识别 USB 链路速率；IMEI 四重验证；全网扫频扫前断网、扫后恢复；5G 载波聚合卡片重构；AT 终端新增 ICCID / IMSI 查询。
