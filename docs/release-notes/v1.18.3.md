# v1.18.3

**主题**：修复手机端看板娘头像被压成椭圆。

补丁小版本，只改移动端头像这一处样式。

## 问题

移动端有一条非等比规则 `.mt-mascot-avatar { width: 75px; height: 65px }`（宽高不等）。桌面端另有 76×76 的正方形规则，在**源码**里靠后、本应生效；但打包压缩时多个 `@media (max-width: 768px)` 块会被**重排**，这条 75×65 在压缩产物里被排到了后面并反超 —— 圆形头像被拉成**椭圆**（容器 75×65、内图 69×59）。

## 修复

在移动端修复块内以更高特异性强制头像为正方形，并确保内图铺满且保持圆形：

```css
.mt5700-hero-card .mt-mascot-avatar.mt-mascot-avatar {
  width: 72px; height: 72px; aspect-ratio: 1 / 1;
}
.mt5700-hero-card .mt-mascot-img.mt-mascot-img {
  width: 100%; height: 100%; border-radius: 50%; object-fit: cover;
}
```

## 实机验证（360px 视口）

| 指标 | 修复前 | 修复后 |
|:--|:--|:--|
| 头像容器 | 75×65（椭圆） | **72×72（正方形）** |
| 头像内图 | 69×59 | **66×66（圆形）** |
| 英雄卡片高度 | 133px | 133px |
