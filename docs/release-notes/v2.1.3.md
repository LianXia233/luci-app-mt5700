**夜间模式配置抽屉可读性修复（#63）** —— 修复普通 UI 模式下开启夜间主题时，配置抽屉背景仍回落浅灰而文字继承浅色导致「浅底浅字」无法辨认的问题。仅改动前端配置抽屉样式与测试，协议与后端行为不变。

### 为什么改

- `config-drawer.js` 原先为 `.mt5700-drawer` 设置 `background: var(--md-sys-color-surface-container-high, var(--at-panel-bg, #f7f7fa))`。在普通模式下，`--md-sys-color-surface-container-high`（仅极简模式 `md3.css` 定义）与 `--at-panel-bg`（全库未定义）均未定义，背景在夜间模式下仍回落为 `#f7f7fa`。
- 同时，抽屉内文字继承 `at.css` / `mt5700.css` 在 `html.at-dark` 下的浅色 `--at-text` / `--mt5700-text`，导致标题与表单标签几乎不可见。

### 主要改动

- **fix(drawer)** 将 `.mt5700-drawer` 背景兜底改为 `--mt5700-float-bg`、文字兜底改为 `--mt5700-text`，并补充 `html.at-dark .mt5700-drawer` 显式暗色背景与文字规则。
- **fix(drawer)** 为 `.mt5700-drawer-close` 补充 `color:inherit;`，并补充 `html.at-dark .mt5700-drawer-err` 与 `html.at-dark .mt5700-drawer-foot .mt5700-btn-ghost` 的暗色对比度规则。
- **test** 更新 `tests/config-drawer-test.js` 新增回归断言，锁定抽屉背景兜底与 `html.at-dark` 样式规则。
- **chore** 版本 2.1.2 → 2.1.3。
