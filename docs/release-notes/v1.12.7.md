**方向可辨版** —— 让日志真正能对着 AT 手册排障。

### 修复

- **日志页渲染中断**：此前只渲染出前两条就停住。根因是渲染循环里的取值路径在数据未就绪时抛异常，被外层 `try` 整体吞掉，后续行全部丢失。现改为逐行容错渲染，单行异常不再影响整页。
- **AT 命令不再被中文化**：`SETAUTODIAL` 这类命令名保持英文原文，只在消息末尾附一句用途（如 `AT^SETAUTODIAL=1,1　（设置自动拨号：开关与拨号方式）`）。命令名一律不替换 —— 替换后就没法跟 AT 手册对照了。

### 新增

- **AT 命令区分方向**，按三层记录，不再是一句含混的「收到 AT 命令」：

  | 日志 | 层级 | 含义 |
  |:--|:--|:--|
  | `前端请求: ATI` | RPC 层 | 页面发来的请求 |
  | `发送 → 模组: AT+CMEE=2` | 通道层 | 本机真正下发到串口的命令 |
  | `接收 ← 模组: OK（共 N 行）` | 应答汇总 | 模组回包，只记末行 + 行数 |

- 前端按方向渲染彩色徽章：**请求=灰 / 发送=蓝 / 接收=绿**，且发送行淡蓝、接收行淡绿 —— 不看徽章也能一眼扫出方向。

### 界面

- 级别下拉与刷新 / 导出按钮改为自写配色：下拉自绘箭头 + 主色描边 + 淡绿底，hover / focus 有反馈；刷新按钮主色实心，导出按钮描边 + hover 反色填充。
- 修正与主题的割裂感：胶囊式分段控件改为**下划线式页签**，面板与列表底色全部透明，只保留一道淡边框。
- **调试级别徽章改为实心紫底 + 白字**。原规则没有背景色，灰字落在浅灰行底上几乎看不见；现紫底白字，与「信息」（蓝）、「警告」（橙）、「错误」（红）形成清晰区分，该行左侧色条同步改为紫色。

### 升级须知

包内前端资源改动较大，升级后若仍是旧样式，请**强刷页面**（`Ctrl+F5`），必要时清理设备缓存：

```sh
rm -f /tmp/luci-indexcache.* && rm -rf /tmp/luci-modulecache/
```
