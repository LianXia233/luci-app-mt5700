**页脚版权署名版** —— 服务配置页底部改为「© 2026 LianXia233 · 开发与维护」并标注 `GPL-3.0-only`；同时把 CI 的产物清理收紧为「每次编译只保留最新一个」。

### 为什么改

- 旧页脚只有作者名，既没有版权年份也没有许可证标识；本仓库按 `GPL-3.0-only` 发布，页脚与 README / LICENSE 的口径需要一致。
- 编译产物（每个 Release 13 个资产、约 9 MB）此前虽有清理步骤，但保留数可手动配置，且 `latest` 标志会让旧 Release 绕过清理 —— 历史包会随版本堆积。改为不可配置的硬保证，每次发布后只留组内最新一个。

### 主要改动

- **feat(ui)** 页脚文案 `© 2026 LianXia233 · 开发与维护` + 纯文本 `GPL-3.0-only` 标识；容器内 1 个主链接（仍指向 GitHub 主仓库，`target="_blank"` + `rel="noopener noreferrer"`）+ 1 个许可证 span，复用 `.mt5700-author` 的居中、换行与 xs 字号，**未改 CSS**，因此 `MT5700_CSS_VERSION` 保持 2.46.9。
- **test** `tests/author-attribution-test.js` 从 29 项扩到 50 项，检查项只增不减；新增四处文案 / SPDX 一致性、历史文案防回退（按完整字面量比对避免子串误判）、许可证节点结构与窄屏换行断言。
- **ci(release)** `build-openwrt.yml` 删除 `keep_releases` / `keep_previews` 输入；发布成功后按 `^v[0-9]` 与 `^preview-` 两组各自只保留组内最新一个，其余 Release 与资产全部删除。预览版发布前仍清空历史 `preview-*` 并清理其 git tag；`debian-v*` 与全部 git tag 不动。
- **chore(release)** 版本号 1.32.8 → 1.32.9，按 AGENTS.md 清单同步全部版本引用与文档下载入口。
- 本版同时包含 `## Unreleased` 中已合入 main 的许可证门禁（cargo-deny / cargo-about 生成第三方依赖清单并注入安装包）、`CDLA-Permissive-2.0` 协议文本与素材授权说明修正。
