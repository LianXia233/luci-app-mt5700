**双 UI 模式版** —— 普通玻璃拟态外观完整保留，新增一套 Material 3 Expressive 的「极简模式」，右下角齿轮入口一键切换并持久化到 UCI；两套外观共用同一份 JS / UCI / RPC / ubus 逻辑，业务零改动。

### 主要改动

- **双模式骨架**：新增 `at-webserver/uimode.js`（UI Mode Manager），模式状态唯一真源是 `<html data-ui-mode="normal|minimal">`；`md3.css` 全部规则带 `html[data-ui-mode="minimal"]` 前缀，普通模式零命中。切换入口为右下角固定齿轮按钮 + 「界面设置」面板（模式分段控件 / 保存说明 / aria-live 状态行），写入 UCI `at-webserver.config.ui_mode` 只 `uci set/save` 不 `apply()`；保存失败双重回滚（`restoreStaged` + `applyDom`），绝不误报成功。
- **MD3 视觉系统**：Design Tokens 落地（色板 / 10 档 typescale / 形状 / 间距 / 高程 / 动效 / state layer）；色板种子取自普通模式品牌色（primary `#7c3aed`、secondary `#0284c7`、tertiary `#db2777`），切模式不换色系；层叠收敛为「每条嵌套路径最多一条边线」的三级 surface 分层。
- **控件状态机**：FAB 补 elevation 3 + hover/pressed state layer + aria-expanded + focus 环；Switch 补齐四态（旋钮 16/24/28dp、两套 state layer、disabled 12%/38%）。
- **图标双表隔离**：`icons.js` 维护 71 个语义键的两套 SVG（normal / minimal），渲染为 `svg[data-mt-icon]`；`scripts/gen-dual-ui-icons.js --check` 做一致性校验。
- **极简模式真卸载**：壁纸层、看板娘 img、星座图光晕/渐变/SMIL 动画均在 JS 层真实移除（非 `display:none`），页面宽度/栅格/断点沿用普通模式原规则。
- **修掉的真实缺陷**：① mt5700.css 末尾 Argon 兼容块用 `background` 简写 + `!important` 把开关悬停色改成灰/蓝，极简层已在 hover/active 显式重写 `background-color`；② `:hover:not(:checked):not(:disabled)` 特异性 (0,6,2) 高于 `:active:not(:disabled)` (0,5,2)，未选中 hover 去掉 `:not(:checked)` 降权，让 pressed 的 12% 生效。
- **chore(version)**：`PKG_VERSION` / `MT5700_UI_VERSION` 1.30.12→1.31.0，发版后所有 JS 模块 URL 的 `?v=` 整体失效，升级用户加载到包含 UI Mode Manager 的新代码（对齐 AGENTS.md 发版版本一致性约定）。
