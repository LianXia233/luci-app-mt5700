# v1.29.0 发布说明（2026-10-23）

## 主题：修复短信中心打开后其它页面卡死（issue #23）

issue #23 反馈：打开短信中心后再进其它页面会卡住，必须等「短信优先模式租约到期自动释放」（实测最长 90s+）才能恢复；日志里 `AT^NTXPOWER?` / `AT^MONSC` / `AT+CGREG?` 全部「等待短信优先模式让出通道」，缓存刷新报「通道已被占用 30s」。

根因是**五层问题叠加**，本版逐层拆掉：

| # | 根因 | 修复 |
|:--|:--|:--|
| 1 | 非短信命令在短信模式下一刀切等 30s（`SMS_MODE_MAX_WAIT`），页面查询与后台巡检同等待遇 | `sms_mode_budget(prio)` 分级：High 3s / Normal 5s / Low·Background **0s 直接跳过** |
| 2 | 缓存刷新只避让长命令、不避让短信模式，每个缓存键各占一个 worker 干等 30s | `do_fetch` 增加 `sms_mode_active()` 避让，本轮跳过、缓存沿用旧值 |
| 3 | 短信事务全程独占 `GatePermit`，无协作让出点，长事务饿死交互命令 | 事务持有超 5s 且门外有排队者时，在命令边界让出一次再以 Sms 优先级抢回 |
| 4 | 租约 TTL 90s / 心跳 30s，页面崩溃后最长阻塞 90s；续约 churn 让门几乎不关 | TTL 30s / 心跳 10s；`openSession` 去重修 churn |
| 5 | 前端 RPC 14s 超时 vs 后端 30s 等待，前端先超时报「后端可能已卡住」 | 错误带 `sms_busy:` 前缀，前端 2s 退避自动重试一次，不计熔断 |

## 用户可见变化

- **其它页面**：短信中心开着的时候，状态页 / 网络页最坏 5s 内必有确定结果（成功或明确提示并自动重试），不再转圈到超时。
- **后台任务**：巡检与缓存刷新在短信模式期间零 AT 下发，日志里「通道已被占用 30s」消失，取而代之的是「本轮跳过缓存刷新」。
- **短信中心**：头部新增通道状态徽章「优先模式生效中 · 后台暂停（剩余 Ns）」；关闭/切走页面后 1s 内释放租约，后台轮询随即恢复。
- **短信功能**：零回归。收发、批量删除、长短信分片、存储切换全部走原事务路径，只是步骤之间多了让出检查点。
- **空态图**：各页面「暂无数据」的占位插画换成「小吱-喜欢」方图（140px、轻浮动效）。

## 技术要点

### 1. 分级预算（`atclient.rs` / `at_queue.rs`）

```rust
pub fn sms_mode_budget(prio: AtPriority) -> Duration {
    match prio {
        AtPriority::High => Duration::from_secs(3),
        AtPriority::Normal => Duration::from_secs(5),
        AtPriority::Low | AtPriority::Background | AtPriority::Sms => Duration::ZERO,
    }
}
```

`wait_clear` 零预算走快速失败（带 `sms_skip:` 前缀，后台任务跳过本轮）；超时错误带 `sms_busy:` 前缀（前端据此重试）。等待机制本身的 Notify 唤醒与 sweep 不变——问题从来在预算分级与调用方不跳过。

### 2. 事务协作让出（`atclient.rs` / `at_queue.rs`）

`SmsTransaction` 新增持有段计时（`held_since`）与 `relinquish/restore`。`run_in_transaction` 每次下发前检查：持有超 `SMS_TX_YIELD_AFTER`（5s）且 `PriLock::has_waiters()` 为真时，交出通道 → 等 100ms 让 Drop 的派发生效 → 以 Sms 优先级抢回。让出只发生在**命令边界**，PDU 会话上下文不跨让出点。

`permit` 用 `Mutex<Option<GatePermit>>` 而非把方法改成 `&mut self`：sms.rs 有六个辅助函数共享 `&SmsTransaction`，改签名波及面不成比例。

### 3. 可观测性

- `SmsTransaction` Drop 输出 `短信事务结束: {label} 耗时 {ms}ms`（logger 非阻塞，Drop 内安全）。
- 前端徽章显示剩余租约时间，与后端 TTL 同源。
