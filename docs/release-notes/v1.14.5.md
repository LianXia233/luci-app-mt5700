**Debian 分支 v1.14.5 为全站英雄区卡片紧凑化排版版**：将 `main` 分支 v1.14.5 的前端改动移植到独立 WebUI。在 v1.14.4 基础上压缩全站 12 个页面顶部英雄区卡片的纵向占用，改善首屏信息密度。

### 英雄区紧凑化

| 项目 | 调整前 | 调整后 |
| --- | --- | --- |
| 卡片内边距 | `24px 28px` | `18px 24px` |
| 卡片内部间距 | `24px` | `20px` |
| 插画尺寸 | `160 × 120` | `124 × 92` |
| 标题字号 | `26px` | `21px` |
| 标题下边距 | `8px` | `5px` |
| 描述字号 / 行高 | `13.5px / 1.6` | `13px / 1.55` |
| 徽标字号 / 内边距 | `12px / 4px 12px` | `11.5px / 3px 10px` |
| 徽标下边距 | `10px` | `8px` |
| 背景光斑 | `260px` 圆形 | `220px` 圆形（上移 -50px） |
| 内容区伸缩基线 | `flex: 1 1 500px` | `flex: 1 1 420px` |

- 整体英雄区高度约由 170px 降至 130px，首屏可多容纳约一行卡片内容。
- 改动为纯 CSS 变量层调整，不涉及任何数据获取与渲染逻辑。

### 移植说明

- 样式改动直接落在 `webui/luci-static/resources/at-webserver/mt5700.css`，该文件由 `index.html` 全站引入，12 个页面（`app.js` 的 `PAGES` 清单）全部生效。
- 本分支不涉及 LuCI 的 `luci.js` 主题样式覆盖问题：英雄区样式自包含于 `mt5700.css`，与 `main` 分支表现一致。
