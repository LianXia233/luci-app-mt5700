## 恢复说明

1.32.12 的工程化收口曾因看板娘渲染与 `tr` 变量遮蔽问题整体回退，1.32.12 随后仅作为看板娘补丁发布。
本版在 1.32.12 基础上**正式恢复**全部工程优化，并合并：

- 1.32.12 的看板娘渲染修复（`syncMascots(root)` + `api.page(node)`）
- `trText()` 防遮蔽修复（避免 `api.table` 的局部 `var tr` 把翻译函数顶掉）
- 新增 `tests/mascot-render-test.js` 与 `tests/i18n-test.js` 双重回归门禁

## 主要改动

### i18n

- 恢复 `po/templates/luci-app-mt5700.pot` 与 `po/zh_Hans/luci-app-mt5700.po`，构建重新产出 `luci-i18n-mt5700-zh-cn`。
- `mt5700.js` 新增 `trText()`：页面标题、卡片、按钮、表单标签、输入占位、下拉选项、空态/提示统一经 LuCI `_()`；无 `_()` 的 Node 环境原样返回。
- 函数名固定为 `trText`，不再使用 `tr`：`api.table` 内的局部 `var tr = E('tr')` 会以函数作用域遮蔽同名翻译函数，历史故障表现为 `tr is not a function`。
- 清理 po 的重复 msgid、过期文案（旧的“留空监听所有接口”等），补齐当前监听范围、认证密钥提示、页面标题与副标题。
- 新增 `tests/i18n-test.js`：校验 pot/po 集合一致、无重复、zh_Hans msgstr 非空、menu.d 标题全覆盖、共享组件确实接入了 `trText()`。

### 看板娘

- `syncMascots(root)` 接受可选作用域；`api.page()` 在页面尚未挂到 `document` 时传入 `node`，确保 `.mt5700-hero-art` 内能插入头像。
- 新增 `tests/mascot-render-test.js`，约束 `syncMascots(root)`、`api.page(node)`、hero-art 容器与 `mascot.png` 版本戳。

### CI 门禁

- `checks.yml` 的 `rust-unit` 增加 `cargo clippy --all-targets -- -D warnings`；Rust 工具链版本改由 `src/rust/rust-toolchain.toml` 单一来源读取。
- 新增 `mock-modem-e2e` job：编译 release 后端 + `npm ci` + `run-e2e.sh`，端到端链路进入合并门禁。
- 新增 shell 门禁：`sh -n` 与 `shellcheck -S error` 覆盖 `*.sh` 及带 `#!/bin/sh` / `#!/bin/ash` 的 init.d、hotplug、uci-defaults。
- 修掉现有 2 条生产 clippy 告警与 19 条测试目标告警（`?` 简化、`is_multiple_of`、常量断言、结构体初始化等）。

### 供应链校验

- `src/rust/rust-toolchain.toml` 固定 Rust `1.98.0`，并声明 `clippy` 组件。
- `scripts/sdk-build.sh` 不再 `curl | sh`：下载固定归档版本的 `rustup-init` 1.29.3 并校验官方 SHA256；zig 0.13.0 与 OpenWrt SDK 也校验官方哈希，校验失败直接中止。
- 构建工作流在发布前生成 `SHA256SUMS`，与 apk/ipk/语言包一起上传 Release；README 与 `ARCH-GUIDE.txt` 给出 `sha256sum -c` 校验命令。
- GPL-3.0 全文随包安装到 `/usr/share/licenses/luci-app-mt5700/LICENSE`，测试保证与仓库根 `LICENSE` 逐字节一致。
