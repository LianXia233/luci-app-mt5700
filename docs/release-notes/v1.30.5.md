# v1.30.5 发布说明 — 夜间模式兼容（issue #26）

## 问题

暗色主题（系统暗色或主题手动夜间模式）下：

- 顶部选择栏（#tabmenu 可滑动页签条）未选中页签几乎看不见；
- 日志页下拉、输入框、表格等仍是白底/浅字，明暗混杂。

## 根因

1. 插件的暗色变量只跟随 `prefers-color-scheme`（系统/浏览器），与主题自身的明暗状态（如 Aurora 顶部按钮、Argon 的夜间模式开关）是两套来源，不一致时页面明暗混杂。
2. CSS 里存在大量 `[data-theme="dark"]` / `.dark-theme` 暗色覆盖，但从未有任何代码设置这些类/属性——暗色适配从未真正生效。
3. 部分主题（Argon 2.x）暗色模式下未选中页签文字仍是写死的深灰 `#404040`，主题自身缺陷，需要插件兜底。
4. 输入框 / 下拉 / 次级按钮 / 表格行等写死了浅色底。

## 修复

- 新增 `at-webserver/theme.js`：识别各主题暗色来源（Aurora `data-darkmode`、Argon 3 `data-argon-mode`、通用标记；Argon 2.x 无标记则实测背景亮度；最后回落 `prefers-color-scheme`），结论写入 `<html class="at-dark|at-light" data-at-theme>`，运行时切换自动跟随。
- `mt5700.css` / `at.css` 的暗色切换全部改为 `html.at-dark` 驱动，激活全部死选择器，并收口写死的浅色组件。
- `tabmenu.js` 实测页签文字对比度，不足 3:1 时加 `.at-tabmenu-fix` 提亮未选中页签（Argon 2.x 暗色；主题正常时零改动）。
- 全局壁纸立绘跟随明暗：暗色主题用深色角色素材，运行时切换自动换图。

## 验证

- 本地 mock（Argon 2.x 暗色 / Aurora 暗色 / Aurora 运行时切换 / 亮色）四场景截图核对：页签条、日志药丸条、下拉、输入框、表格行、卡片、立绘均正确联动。
- `node tests/theme-test.js` 44 项、`node tests/tabmenu-test.js` 38 项、存量 170 项单测全部通过。
