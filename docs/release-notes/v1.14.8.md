**v1.14.8 为「设备标识（IMEI）」卡片排版优化版**：在 v1.14.7 基础上，仅调整模组设置页 IMEI 卡片的前端展示层。

### 排版调整

- 「当前 IMEI」取值：`mt5700-inline` 行内提示 → **带边框取值展示块**（label 左 + 等宽字体取值右，16px 加粗、字距加宽），置于卡片顶部作为视觉焦点。
- 「修改 IMEI」按钮：跟随取值行内 → 独立一行右对齐。
- 四重验证说明与法律风险提示（fieldNote）：顶部 → 底部次级信息区。

### 安全边界（重要）

- 本次改动**仅限前端 UI 展示层**：
  - `imeiEl` DOM 节点保持同一实例，仍由 AT+CGSN 读取回填（fetchDeviceInfo）与写入成功后的更新逻辑驱动；
  - 四重验证流程（新 IMEI + Luhn 校验 → 一致性确认 → 归属验证 → 最终确认）、`AT^PHYNUM` 写入命令与全部数据流**零改动**；
  - 页面加载与验证过程仅执行只读查询，不触发任何 IMEI 写操作。

- README 版本号与安装示例同步至 v1.14.8。
