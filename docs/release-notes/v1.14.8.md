**Debian 分支 v1.14.8 为「设备标识（IMEI）」卡片排版优化版**：将 `main` 分支 v1.14.8 的前端改动移植到独立 WebUI。**严格限定在 UI 展示层**。

### 排版优化

- IMEI 数值由「单行纯文本」改为**取值展示块**（`.mt-imei-value`）：左侧字段标签、右侧 IMEI 数值（16px 等宽字体），标签与值基线对齐、间距均匀。
- 卡片内新增 `mt-imei` 作用域样式（与 v1.14.6 的 `mt-sysctl-*` 同样采用页内注入，不污染全局）。
- 操作条移至数值展示块下方，`fieldNote` 说明文字沉底排版，整体层级为「标题 → 数值 → 操作 → 说明」。

### 功能零改动（硬约束）

以下内容与 v1.14.7 **完全一致，本次未做任何修改**：

- **IMEI 取值**：仍为 `send('ATI')` 响应解析，`imeiEl` 节点实例保持同一引用（仅调整其父容器与样式类，不替换节点）；
- **IMEI 显示逻辑**：字段标签、取值来源、脱敏/格式处理均未变；
- **AT 下发命令**：`AT^PHYNUM` 写码调用零改动；
- **四重验证流程**：`luhnValid` 校验 → 归属地验证 → 终端确认 → 写入，逐环节逻辑与顺序不变；
- **读写接口**：与后端 `/api/*` 的交互契约不变。

### 移植说明

- 改动落在 `webui/luci-static/resources/view/at-webserver/modem_settings.js`，属纯 DOM/样式层。
- 验证方式与 `main` 分支一致：劫持 `AtWs.client.sendCommand` 为记录数组（命令仅记录、绝不下发），确认渲染正常且无命令被派发。
