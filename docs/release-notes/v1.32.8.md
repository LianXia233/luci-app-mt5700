**版本口径修正版** —— 后端自报版本不再来自 `Cargo.toml` 的陈旧元数据，改由 `PKG_VERSION` 在构建期注入，`--version` 与启动日志从此和包版本逐版本对齐。

### 为什么改

- 后端版本一直是 `const VERSION: &str = env!("CARGO_PKG_VERSION")`，取值来自 `src/rust/Cargo.toml` 的 `version`，该值是 1.29.0 且此后每次发版都没有再动。结果是包版本已经到 1.32.7，设备上的 `at-webserver-rust --version` 与 `at-webserver 1.29.0 启动中` 仍在报 1.29.0。
- 这个数字只出现在自报与日志里，不影响功能，但排障时无法从日志判断设备上实际运行的是哪一版后端，也容易在对比 issue 时把现象归错版本。

### 主要改动

- **feat(rust) 单一来源**：顶层 `Makefile` 增加 `export MT5700_VERSION:=$(PKG_VERSION)`，`src/Makefile` 在 `cargo build` 那一行把 `MT5700_VERSION="$(MT5700_VERSION)"` 传进构建环境；`main.rs` 的 `VERSION` 改为 `match option_env!("MT5700_VERSION") { Some(v) => v, None => env!("CARGO_PKG_VERSION") }`。发版只需改 `PKG_VERSION`，Rust 侧无需再改代码。
- **feat(build) 缺省路径**：`src/Makefile` 在拿不到 `MT5700_VERSION` 时（直接在 `src/` 下执行 `make compile`）从 `$(CURDIR)/../Makefile` 解析 `PKG_VERSION`，并把解析结果打印在 `cargo build` 那行日志里，避免子 make 取不到顶层变量时静默沿用旧值。两条路都落空时才由 Rust 侧回退 `Cargo.toml`，即脱离 OpenWrt 构建的本地 `cargo build` / `cargo test` 仍然可编译。
- **chore(release)** `src/rust/Cargo.toml` 与 `src/rust/Cargo.lock` 的 `version` 同步到 1.32.8（`cargo test --locked` 依赖二者一致），包元数据与包版本对齐。
- **test** 新增 `tests/rust-version-test.js`：断言 `PKG_VERSION` 合法且被导出、`src/Makefile` 确实传参并有上级解析兜底、`main.rs` 优先读注入值且保留 `CARGO_PKG_VERSION` 回退、`Cargo.toml` 与 `Cargo.lock` 版本都等于 `PKG_VERSION`。
- **docs(agents)** 发版版本一致性清单补入 `src/rust/Cargo.toml` 的 `version`，并新增「Rust 后端版本与包版本联动」小节，写明四个环节（单一来源 / 注入 / 消费 / 兜底）与复核命令。

### 验证记录

- `node tests/rust-version-test.js` 通过（10 项断言）；`node tests/usage-source-test.js` 的 UI 版本戳断言同步到 1.32.8 后通过。
- `cd src/rust && cargo test`：356 passed / 0 failed / 2 ignored（与上一版基线一致，本版未改 AT 逻辑、接口字段与前端渲染）。
- 本地 `cargo build`（不传 `MT5700_VERSION`）可编译，`--version` 回退为 `Cargo.toml` 的 1.32.8；注入 `MT5700_VERSION` 后按注入值输出。
- 未验证项：交叉编译产物（OpenWrt SDK 内的 cargo 调用链）需等下一次云构建才能实测；本版未改动 `MT5700_CSS_VERSION`（未动样式文件）。

### 升级提示

- 覆盖安装即可，无配置迁移、无接口变化。`MT5700_UI_VERSION` 1.32.7 → 1.32.8，浏览器模块缓存整体失效；`MT5700_CSS_VERSION` 保持 2.46.9。
- 升级后可执行 `/usr/bin/at-webserver-rust --version`，输出中的版本应与 `apk list --installed | grep luci-app-mt5700` 一致。
