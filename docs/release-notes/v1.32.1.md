**样式微调 + 实机回归修复版** —— 「本次使用量 → 统计来源」改为刚好包住选项文字的紧凑小方框，去掉突兀的白色大胶囊与过宽的紫色圆角胶囊；修复 v1.32.0 在实机上 `netrate` 因 ucode 单参数 `split()` 返回 null 而整条 RPC 失败的问题；并补上「无模组 WAN 口时按默认 WAN 口物理网卡统计」的识别判据。全程不回退 LAN / `br-lan`。

### 主要改动

- **feat(ui) 流量统计图表跟随统计来源切换**：此前切换「统计来源」后，下行 / 上行速率火花线仍保留旧来源的 12 个历史点，且 `renderSpeedUI()` 被使用量轮询、清零、持久化等 9 处复用、每次都推一个点，一秒混入多个重复点；两套计数器绝对值不同还会画出虚假尖峰。新增 `sparkSource` 与 `resetTrafficSeries()`，切源时清空历史 / 速率 / 采样基线，并立即按新来源重新采样；`sampleUsage()` 也能发现页面外（UCI / 其它会话）的来源变化。推点收敛到 `pushTrafficSample()`，只在速率采样后调用，采样基线新增 `source` 字段，避免 netdev 的 sysfs 累计与 modem 的 DS 累计混算。卡片头标签改为「实时 · 物理网卡 / 实时 · 模组 AT」，图表悬停提示同步标明来源；`modem` 来源下不再把 `modem:^DSFLOWQRY` 这个来源标签写进「数据通信接口」。
- **feat(usage) 无模组 WAN 口时回落默认 WAN 口物理网卡**：部分设备不为模组单独建 WAN 逻辑接口，而是直接复用出厂默认 `wan`。Rust `select_wan_netdev()` 与 rpcd ucode `detectWanDevice()` 在「模组 WAN 口（WAN 区域 ∩ USB 网口）」之后新增第 2 级：仅当 `wan` 逻辑接口确实属于 WAN 区域时，按 `network.wan` 的 `device` / 旧式 `ifname` / `@alias` 递归反查物理网卡，校验非 LAN 侧且计数器可读后采用；之后才轮到 WAN 区域其它成员与「非 LAN 归属的 USB 网卡」回落。实机 `network.wan.device='eth1'` 即该判据的回落目标，模组正常时仍优先 `eth2`。DNS 下发与 `IFACE_4G` 接口创建判据不变，不会把主 WAN 的 DNS 或拨号接口误改到模组口上。
- **feat(usage) 数据通信接口优先模组物理网卡**：「设备信息 → 数据通信接口」此前只在 `netrate` 成功时才赋值，速率 RPC 一失败就显示 `—`。改为优先取 `state.usage.device`（后端按 WAN 区域 ∩ USB 模组网口识别、每秒刷新），`modem` 来源下该字段是 DS 来源标签故不当网卡名用，再回落速率采样值；init.d 的 `resolve_ifaces()` 自动分支也改为复用 `dns_direct_ifaces()` 先做 WAN 归属校验，再退回纯物理网卡反查，避免误选同网卡的 LAN 侧接口。
- **fix(usage) 实机 netrate 回归**：v1.32.0 的 WAN 区域解析有 8 处 `split(trim(x))` 单参数调用，而实机 ucode 的 `split()` 单参数返回 `null`，`networkDevices()` 随即抛 `left-hand side expression is null`，rpcd 返回 `Unknown error`，实时速率取不到数。全部改为显式 `' '` 分隔符；`detectWanDevice()` 第 2 级跳过空项（实机 `split('', ' ')` 返回 `['']`），保住「候选全无 → WAN 侧 USB 网卡」回落。Node 测试里的 `split` / `length` 模拟同步改成实机语义并加源码残留断言，避免同类回归再次漏测。

- **style(usage) 根因**：来源下拉框此前复用「每月清零」天数输入框的 `.mt-usage-days`，而 `mt5700.css` 里另有一条全局 `.mt5700-select, .cbi-input-select, select` 深度美化规则，用 `!important` 强制白底、深蓝紫等宽粗体、13.5px 字号与 `8px 36px` 大内边距。`.mt-usage-days` 只夺回了 padding / font-size，背景色与字色仍被全局规则占住，于是在浅色卡片里变成一枚白色大胶囊配蓝紫色粗体中文。
- **style(usage) 独立控件**：来源行加 `.source`，下拉改用 `.mt-usage-source`，设备名提示加 `.mt-usage-source-hint`。以更高特异性 + `!important` 收回样式：透明底、1px 细描边、4px 小圆角方框、10.5px 次要文字色、继承字体、仅一枚紧贴文字的 6×4 中性灰小箭头；不设 `min-width` / `max-width`，宽度完全由「物理网卡 / 模组 AT」文字决定，hover / focus 只改边框与文字色，不再整块染紫；暗色主题单独适配展开的选项弹层。
- **style(usage) 层级收敛**：行内边距 4px→3px，标签显式透明底与统一字色，`eth2` 一类设备名改淡色等宽小字、前置 `·` 分隔并超长省略，控件与提示不再挤在一起。
